# 036 -- Numbered but unbuilt method words that have no method code (.abs .sqrt .floor .digits, .to_binary on a hex, .at .substring .split .trim .starts_with .ends_with .resolved) are refused as "not one of its methods -- only a spacesuit has capsules", "no capsule named X" or S201, not S210 NOT_BUILT_YET

**Found:** 2026-09-26, satl 004 revision 08 build 0099 (/home/madness/code/cxx/satellite/build/satl), by running ordinary programs against it.  
**Area:** binary hex color infinity bool, integers, realistic programs, strings  
**Kind:** contradicts-help  
**Severity:** medium

## What happens

7 of the 13 not-built string words (.at .substring .starts_with .ends_with .split .trim .resolved) are refused as 'not one of its methods -- only a spacesuit has capsules', 'no capsule named X' or S201 'X has no satellite.variable line', not S210.

## What it should do

S210 NOT_BUILT_YET before anything runs, as for s.size: 'satl(check): in satellite.main, s.split is not built for satellite.variable.string yet' (exit 14). A literal should get 'that string.split is not built for a string yet'.

satellite.help/satellite.variable.string/help_text.txt: 'Numbered under word 1 6 1 and not built yet in satellite 004: .size .empty .contains(x) .replace(a, b) .append(x) .clear .at(n) .substring(start, end) .starts_with(x) .ends_with(x) .split(separator) .trim .resolved ... Each is refused before anything runs (S210)'. ERROR.md marks 'Only seven names lex as methods, and the rest say "no capsule named x"' FIXED: 'every string method is a method code now, and an unbuilt one is told so before anything runs'.

## Variants

Name form, all S110 'X is not one of its methods' (exit 13): s.at(1), s.substring(1, 2), s.starts_with("a"), s.ends_with("a"), s.split(","), s.trim, s.trim(), s.resolved, s.resolved(). Literal form: "abc".at(1), .substring(1, 2), .starts_with, .ends_with, .split, .trim(), .resolved() get S110 'no capsule named X' (13). "abc".trim and "abc".resolved with no brackets get S201 NAME_NOT_DECLARED 'trim has no satellite.variable line declaring it' (exit 25). Correct S210 from the checker: .size, .size(), .empty, .empty(), .contains, .replace (on a name), .append, .clear, .clear(), on a name and on a literal. Every refusal comes before anything runs, so the problem is the wording, not the timing.

## Where it comes from

satellite/bytecode/token_codes.hpp:334 method_code_of (generated by satellite/bytecode/make_token_codes.py:166) has no spelling for at, substring, starts_with, ends_with, split, trim or resolved. They lex as name_token, so satellite/bytecode/program_check.cpp:1218-1234 gives the 'not one of its methods' refusal, and a literal's .name is read as a capsule call or a bare name.

The seven words were never added to the method spelling table (REGISTRY or make_token_codes), so the lexer never makes a method code of them. The checker's S210 path (program_check.cpp:753 on a name, 1542-1551 on a literal) never sees them.
