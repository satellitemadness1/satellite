# CXX23/M261 — `std::count`, `std::count_if`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
auto n = std::count_if(v.begin(), v.end(), is_even);
```

## Why

An index loop and a counter. `count_if` needs [M32](../SATELLITE/M32-capsules-as-values.md).
