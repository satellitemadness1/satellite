# CXX23/M241 — indexing a string `s[i]`, `s.at(i)`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
char c = s.at(3);
```

## satellite

```
satellite.variable.string c = s.at(3)
```

## What differs

Answers a one-byte string, not a character. It is a byte index, like C++'s, and [M45](../CXX26/M45.md) says what that means for UTF-8.
