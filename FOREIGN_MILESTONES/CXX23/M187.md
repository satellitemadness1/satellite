# CXX23/M187 — template specialisation, full and partial

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M31](../SATELLITE/M31-user-generics.md).**

## C++

```cpp
template <> struct Hash<std::string> { };
```

## Why

Follows [M31](../SATELLITE/M31-user-generics.md). **Full specialisation is the likely boundary.** Partial specialisation is a second pattern-matching language inside the type system, and [M31](../SATELLITE/M31-user-generics.md) asks for a decision on monomorphisation before anything that deep.
