# CXX23/M63 — `__has_include`

**Introduced:** C++17. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
#if __has_include(<optional>)
```

## Why

**There is one include and it is always there.** The question underneath, *is
this feature available here?*, is [M41](../CXX26/M41.md)'s `installed()`, asked of the language's
own numbering rather than of a header search path.
