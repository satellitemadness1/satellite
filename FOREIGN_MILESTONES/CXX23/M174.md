# CXX23/M174 — conversion operators `operator bool()`

**Introduced:** C++98 / C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
explicit operator bool() const;
```

## Why

[M38](../SATELLITE/M38-operator-overloading.md) limits user operators to `+`, `==` and `<` on purpose, and names conversion operators as where C++ overloading became unreadable. A suit answers `call_is_valid()` instead.
