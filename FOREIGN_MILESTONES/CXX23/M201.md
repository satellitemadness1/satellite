# CXX23/M201 — function pointers

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M32](../SATELLITE/M32-capsules-as-values.md).**

## C++

```cpp
int (*op)(int, int) = add;
```

## Why

A capsule can be called and not passed. `satellite.variable.capsule` is numbered, and [M32](../SATELLITE/M32-capsules-as-values.md) is what lets it hold one.
