# CXX23/M170 — default member initialisers

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
struct S { int x = 3; };
```

## satellite

```
satellite.spacesuit s()
{
    satellite.protected
    {
        satellite.variable.number x = 3
    }
}
```

## What differs

A field's initialiser is written where it is declared. `example/class_test.satl` sets a binary field this way.
