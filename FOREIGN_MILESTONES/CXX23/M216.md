# CXX23/M216 — `std::unreachable`

**Introduced:** C++23. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
default: std::unreachable();
```

## Why

Marking code unreachable is permission for undefined behaviour. The satellite version is to check it: [M42](../CXX26/M42.md), or [M30](../SATELLITE/M30-switch-and-match.md)'s exhaustiveness check.
