# CXX23/M91 — escape sequences `\n`, `\t`, `\"`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
std::cout << "a\tb\n";
```

## satellite

```
satellite.console.display("a\tb")
```

## What differs

Checked 2026-09-12: `\t`, `\n` and `\"` inside a string literal print as C++ would print them.
