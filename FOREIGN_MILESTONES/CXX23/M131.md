# CXX23/M131 — logical not `!`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
if (!ready) { }
```

## satellite

```
satellite.statement.if (!ready) { ... }
```

## What differs

**Checked 2026-09-12: `!` works.** With `ready` false, `!ready` took the branch.

**This corrects the catalogue.** Row 20 lists `!` together with `&&` and `||`
under [M28](../SATELLITE/M28-logical-operators.md). `&&` and `||` are still missing; `!` is not. [M28](../SATELLITE/M28-logical-operators.md)'s own page talks
about adding `not`, so it should say that `!` already exists.
