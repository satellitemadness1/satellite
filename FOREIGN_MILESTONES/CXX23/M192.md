# CXX23/M192 — `<type_traits>`

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
std::is_same_v<T, int>
```

## Why

Compile-time type computation is template metaprogramming, which satellite is not getting. A *program* asking what something is at run time is [M41](../CXX26/M41.md).
