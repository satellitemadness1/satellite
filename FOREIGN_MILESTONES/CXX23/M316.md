# CXX23/M316 — plain `struct` with only data

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
struct Point { int x; int y; };
```

## satellite

```
satellite.spacesuit point()
{
    satellite.protected
    {
        satellite.variable.number x = 0
        satellite.variable.number y = 0
    }
    satellite.public
    {
        satellite.capsule call_x() satellite.returns(satellite.variable.number) { satellite.return(x) }
    }
}
```

## What differs

**Fields are never public** (DESIGN §12: a field is reachable only from inside the spacesuit), so a C struct needs an accessor per field. That is the cost for a plain data type, and it is paid on purpose.
