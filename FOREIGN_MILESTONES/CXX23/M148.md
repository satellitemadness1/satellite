# CXX23/M148 — `return` out of a loop

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
for (int i = 0; i < 10; ++i) if (i == 3) return i;
```

## satellite

```
satellite.statement.for (satellite.variable.number i = 0; i < 10; i = i + 1)
{
    satellite.statement.if (i == 3) { satellite.return(i) }
}
```

## What differs

Checked 2026-09-12: this answered `3`. **It is the cleanest workaround for
[M27](../SATELLITE/M27-break-and-continue.md)** until `break` exists: move the loop into its own capsule and `return`
from it.
