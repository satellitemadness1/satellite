# CXX23/M208 — `constinit`

**Introduced:** C++20. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M34](../SATELLITE/M34-compile-time-evaluation.md).**

## C++

```cpp
constinit int table_size = compute();
```

## Why

Guaranteeing a global is initialised before the program runs is [M34](../SATELLITE/M34-compile-time-evaluation.md). `satellite.library` values from literals are already resolved at parse time.
