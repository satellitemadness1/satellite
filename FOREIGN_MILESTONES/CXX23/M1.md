# CXX23/M1 — `int main()`

**Standard:** C++23 (ISO/IEC 14882:2024) §6.9.3.1. Present since C++98.
**Answer: satellite says it.**

## C++

```cpp
int main(int argc, char **argv) { return 0; }
```

## satellite

```
satellite.capsule satellite.main(satellite.container.list<satellite.variable.string> arguments)
{
    satellite.return(satellite)
}
```

## What differs, and it is not cosmetic

**`argc` is gone, because a list knows its own size** — `arguments.size()`. The
two-parameter form is C's answer to an array that does not, and satellite's list
does.

**The return is `satellite` and not `0`.** DESIGN §7.7: the program answers with
the language object rather than a status number; `satl`'s exit code is decided by
whether the run refused, not by what main handed back.

**There is exactly one entry point and it is named.** `satellite.main` is a
reserved path, so a file cannot declare a second one, and there is no equivalent
of a static initialiser running before it.
