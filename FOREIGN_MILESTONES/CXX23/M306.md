# CXX23/M306 — `std::condition_variable`

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M40](../SATELLITE/M40-locks-and-atomics.md).**

## C++

```cpp
cv.wait(lock, [] { return ready; });
```

## Why

Waiting for a condition needs a lock to wait on, and there is none. [M40](../SATELLITE/M40-locks-and-atomics.md).
