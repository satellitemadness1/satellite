# CXX23/M258 — `resize`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
v.resize(10);
```

## satellite

```
v.truncate(10)
```

## What differs

`truncate(n)` shrinks. There is no growing counterpart that fills with a default, so growing is a loop of appends.
