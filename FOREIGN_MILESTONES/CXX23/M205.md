# CXX23/M205 — `std::bind`, `std::bind_front`, `std::invoke`

**Introduced:** C++11 / C++17 / C++20. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M32](../SATELLITE/M32-capsules-as-values.md).**

## C++

```cpp
auto f = std::bind_front(&Suit::method, suit);
```

## Why

Calling or partially applying a callable value. [M32](../SATELLITE/M32-capsules-as-values.md).
