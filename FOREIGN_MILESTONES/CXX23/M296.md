# CXX23/M296 — binary file I/O, `seekg`, `tellg`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: open — no milestone and no refusal yet; this needs a decision.**

## C++

```cpp
in.seekg(128); in.read(buf, 16);
```

## Why

**Files are text lines and whole reads.** `read_line`, `read_all`, `write`
and `write_line` exist, and there is no seek, no byte count and no binary mode.

**Open.** Combined with [M44](../CXX26/M44.md) (a file's bytes at parse time), this is where
`satellite.variable.binary` would meet a file.
