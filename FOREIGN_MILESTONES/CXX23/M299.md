# CXX23/M299 — `create_directory`, `rename`, `copy`

**Introduced:** C++17. Present in C++23 (ISO/IEC 14882:2024).
**Answer: open — no milestone and no refusal yet; this needs a decision.**

## C++

```cpp
std::filesystem::create_directories(p);
```

## Why

**Not in `satl --words`.** A program can list, change into and delete directories but not create one, or rename or copy a file. Open, and it rounds out `satellite.directory`.
