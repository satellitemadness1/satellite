# CXX23/M161 — member functions calling each other

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
void Suit::call_erase() { erase(); }
```

## satellite

```
satellite.capsule call_erase()
{
    erase_binary_data()
}
```

## What differs

Inside a spacesuit, a capsule calls another by its bare name, and reads fields by bare name too. `example/class_test.satl` does both.
