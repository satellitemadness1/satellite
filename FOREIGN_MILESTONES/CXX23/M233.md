# CXX23/M233 — `find` and `substr`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
auto at = s.find("tell");
auto part = s.substr(2, 2);
```

## satellite

```
satellite.variable.number at = s.find("tell")
satellite.variable.string part = s.substring(2, 4)
```

## What differs

**`substring` takes an END, not a LENGTH.** Checked 2026-09-12:
`"abcdef".substring(2, 4)` is `"cd"`. The C++ call `substr(2, 4)` would give
`"cdef"`. A C++ reader will get this wrong exactly once.
