# CXX23/M175 — `operator[]`, `operator()`, multidimensional `operator[]`

**Introduced:** C++98 / C++23. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
T &operator[](std::size_t);
bool operator()(int) const;
```

## Why

Excluded by [M38](../SATELLITE/M38-operator-overloading.md) for the same reason as conversions. A function object's real use, passing behaviour around, is [M32](../SATELLITE/M32-capsules-as-values.md).
