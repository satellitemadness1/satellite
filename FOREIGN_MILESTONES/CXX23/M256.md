# CXX23/M256 — walking a map's keys and values

**Introduced:** C++98 / C++17. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
for (const auto &[k, v] : m)
```

## satellite

```
satellite.container.list<satellite.variable.string> ks = m.keys()
satellite.statement.for (satellite.variable.number i = 0; i < ks.size(); i = i + 1)
{
    satellite.variable.string k = ks[i]
    satellite.variable.number v = m.get(k)
}
```

## What differs

`keys()` and `values()` answer lists. The loop is range-for (open, above) and the binding is [M35](../SATELLITE/M35-structured-bindings.md).
