# CXX23/M149 — semicolons and several statements on one line

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
a = 1; b = 2;
```

## satellite

```
a = 1
b = 2
```

## What differs

A statement ends at the end of its line. A trailing `;` is refused (`S0203`), and the message says to put the second statement on its own line.
