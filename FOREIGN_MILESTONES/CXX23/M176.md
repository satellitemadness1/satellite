# CXX23/M176 — abstract classes and pure `virtual`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M31](../SATELLITE/M31-user-generics.md).**

## C++

```cpp
struct Shape { virtual double area() const = 0; };
```

## Why

An interface with no body is the same question as Java's `interface` and Rust's `trait`, which `foreign.cpp` sends to [M31](../SATELLITE/M31-user-generics.md) and "a decision after it".
