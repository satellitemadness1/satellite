# CXX23/M130 — comparison `==`, `!=`, `<`, `<=`, `>`, `>=`

**Introduced:** C++98 / C++20. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
if (a != b && a >= c)
```

## satellite

```
satellite.statement.if (a != b) { ... }
```

## What differs

All six work on numbers. **On strings, only `==` and `!=` work**, and `<` is
refused with `S0712` (*string has no order*). A spacesuit cannot be compared at
all until [M38](../SATELLITE/M38-operator-overloading.md). Combining two comparisons is [M28](../SATELLITE/M28-logical-operators.md).
