# CXX23/M226 — `std::optional` monadic `and_then`, `transform`, `or_else`

**Introduced:** C++23. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M32](../SATELLITE/M32-capsules-as-values.md).**

## C++

```cpp
auto name = find(id).transform(&User::name).value_or("?");
```

## Why

Needs a callable to pass (M32) and chaining to write it (M29). Today it is a `holding()` check and a named value.
