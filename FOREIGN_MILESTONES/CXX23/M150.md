# CXX23/M150 — several declarators `int a = 1, b = 2;`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
int a = 1, b = 2;
```

## satellite

```
satellite.variable.number a = 1
satellite.variable.number b = 2
```

## What differs

One declaration per line. `S0203` on the comma.
