# CXX23/M260 — `std::find`, `std::find_if`

**Introduced:** C++98 / C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
auto it = std::find(v.begin(), v.end(), x);
```

## satellite

```
satellite.variable.number at = v.index_of(x)
```

## What differs

`index_of(x)` and `contains(x)` cover finding a value. `find_if` takes a predicate, which is [M32](../SATELLITE/M32-capsules-as-values.md).
