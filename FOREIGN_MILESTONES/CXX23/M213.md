# CXX23/M213 — `std::error_code` and `errno`

**Introduced:** C++98 / C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
std::error_code ec;
std::filesystem::remove(p, ec);
```

## satellite

```
satellite.variable.file f = satellite.file.open(path, "read")
satellite.statement.if (f.ok() == satellite.bool.false) { satellite.console.display(f.error()) }
```

## What differs

A file answers `ok()` and `error()` rather than refusing, and [M33](../SATELLITE/M33-catching-a-refusal.md)'s page names that as the pattern to generalise. `satellite.system.delete(x)` also answers whether the thing is gone.
