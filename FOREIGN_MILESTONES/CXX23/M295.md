# CXX23/M295 — `std::endl`, `std::flush`, stream manipulators

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
std::cout << x << std::endl;
```

## satellite

```
satellite.console.display(x)
```

## What differs

`display` adds the newline. There are no manipulators, which is the format-string loss [M3](M3.md) records.
