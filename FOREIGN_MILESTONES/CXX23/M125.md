# CXX23/M125 — `%`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
int r = 7 % 3;
```

## satellite

```
satellite.variable.number r = 7 % 3
```

## What differs

Checked 2026-09-12: `7 % 3` prints `1`. `satellite.variable.number.modulus(a, b)` also exists as a method.
