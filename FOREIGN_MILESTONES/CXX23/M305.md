# CXX23/M305 — `std::jthread` and `std::stop_token`

**Introduced:** C++20. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
std::jthread t([](std::stop_token st) { while (!st.stop_requested()) { } });
```

## satellite

```
satellite.variable.thread t = satellite.thread.new(work(x))
t.start()
t.join()
```

## What differs

Threads start and join ([M45](M45.md)). **Asking a thread to stop is not in the word tree**, and the only shared signal is a `satellite.library` flag, which [M40](../SATELLITE/M40-locks-and-atomics.md)'s open questions cover.
