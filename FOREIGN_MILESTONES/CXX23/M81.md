# CXX23/M81 — `char` and character literals `'a'`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
char c = 'a';
char first = s[0];
```

## satellite

```
satellite.variable.string c = "a"
satellite.variable.string first = s.at(0)
```

## What differs

**There is no character type, and `'a'` does not lex.** Checked 2026-09-12:
`'a'` is `S0231`. A character is a one-byte string, and `s.at(n)` answers one.
It is a *byte*, not a character. See [M45](../CXX26/M45.md) for what that means outside ASCII.
