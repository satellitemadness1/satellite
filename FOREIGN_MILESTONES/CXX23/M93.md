# CXX23/M93 — `bool`, `true`, `false`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
bool ready = (a == b);
```

## satellite

```
satellite.variable.bool ready = a == b
```

## What differs

Checked 2026-09-12: a comparison answers a `bool`, and `satellite.bool.true` and `.false` are the literals.
