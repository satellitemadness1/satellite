# CXX23/M275 — `views::join_with` and joining strings

**Introduced:** C++23. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
auto line = parts | std::views::join_with(',') | std::ranges::to<std::string>();
```

## satellite

```
satellite.variable.string line = parts.join(",")
```

## What differs

`join(separator)` is a list method.
