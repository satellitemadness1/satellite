# CXX23/M207 — C variadic functions `...`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
int sum(int count, ...);
```

## Why

The arity is part of a path's identity (PLAN.md §8 on `satellite.network`:
*the arity is the identity*), so a variable argument count is a different shape,
not a flag. To pass many values, pass a list. A type-safe variadic is [M31](../SATELLITE/M31-user-generics.md)'s
parameter packs.
