# CXX23/M224 — `std::min`, `std::max`, `std::clamp`, `std::abs`

**Introduced:** C++98 / C++17. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
int m = std::min(a, b);
int c = std::clamp(v, lo, hi);
```

## satellite

```
satellite.variable.number m = a.min(b)
satellite.variable.number c = v.clamp(lo, hi)
```

## What differs

Methods on the first value. `a.max(b)`, `n.abs()`, `v.clamp(lo, hi)`. A list answers its own `min()`, `max()` and `sum()`.
