# CXX23/M134 — `sizeof...` on a parameter pack

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M31](../SATELLITE/M31-user-generics.md).**

## C++

```cpp
sizeof...(Args)
```

## Why

Parameter packs are [M37](M37.md) (C++ packs), which is [M31](../SATELLITE/M31-user-generics.md). There is nothing to count until a program can write a variadic capsule.
