# CXX23/M211 — custom exception types and `std::exception`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M33](../SATELLITE/M33-catching-a-refusal.md).**

## C++

```cpp
struct ParseError : std::runtime_error { using runtime_error::runtime_error; };
```

## Why

[M33](../SATELLITE/M33-catching-a-refusal.md), which is deliberately `std::expected` rather than `try`. A refusal would become a value you can inspect, not a class hierarchy you catch by type.
