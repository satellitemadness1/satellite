# CXX23/M76 — `[[fallthrough]]`

**Introduced:** C++17. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
case 1: a(); [[fallthrough]];
```

## Why

[M30](../SATELLITE/M30-switch-and-match.md) decides that satellite's `switch` has no fallthrough, so there is nothing to mark.
