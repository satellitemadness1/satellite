# CXX23/M145 — a declaration in the `for` header

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
for (int i = 0; i < 5; ++i)
```

## satellite

```
satellite.statement.for (satellite.variable.number i = 0; i < 5; i = i + 1)
```

`example/scalars.satl` does exactly this.
