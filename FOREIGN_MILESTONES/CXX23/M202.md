# CXX23/M202 — pointers to members

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
int Point::*field = &Point::x;
```

## Why

Field access is only through the suit's own verbs, which is DESIGN §12's rule. The *method* half, a callable bound to a suit, is [M32](../SATELLITE/M32-capsules-as-values.md).
