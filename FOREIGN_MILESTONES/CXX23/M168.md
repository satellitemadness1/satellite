# CXX23/M168 — delegating constructors

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: open — no milestone and no refusal yet; this needs a decision.**

## C++

```cpp
Point() : Point(0, 0) { }
```

## Why

Follows [M27](M27.md) (constructors, partial). A spacesuit has field defaults and no constructor arguments yet, so one constructor has nothing to delegate to another.
