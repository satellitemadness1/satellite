# CXX23/M235 — `std::to_string`, `std::stoi`, `std::stod`

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
int n = std::stoi("42");
```

## satellite

```
satellite.variable.string text = "42"
satellite.variable.number n = text.to_number()
```

## What differs

Checked 2026-09-12: `"42".to_number()` plus 1 printed `43`. One conversion serves both integers and decimals, because there is one number type.
