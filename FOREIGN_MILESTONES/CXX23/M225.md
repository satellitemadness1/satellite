# CXX23/M225 — `std::hash` and user types as map keys

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M38](../SATELLITE/M38-operator-overloading.md).**

## C++

```cpp
template <> struct std::hash<Point> { };
```

## Why

A map key needs equality, and a spacesuit has no `==` until [M38](../SATELLITE/M38-operator-overloading.md). Strings and numbers work as keys today.
