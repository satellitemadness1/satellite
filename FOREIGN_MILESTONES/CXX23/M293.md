# CXX23/M293 — `std::getline(std::cin, line)`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
std::getline(std::cin, line);
```

## satellite

```
satellite.variable.string line = satellite.console.input()
```

## What differs

Input is line-at-a-time already. For files, `f.read_line()`.
