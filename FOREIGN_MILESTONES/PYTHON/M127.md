# PYTHON/M127 — `assert`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M42](../CXX26/M42.md).**

## Python

```python
assert count >= 0, "count went negative"
```

## Why

[M42](../CXX26/M42.md) (contracts). **Python removes `assert` under `-O`; satellite's would not**, since satellite has no build modes. The statement form is the smaller half and could come first.
