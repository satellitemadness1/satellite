# PYTHON/M83 — `tuple`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M35](../SATELLITE/M35-structured-bindings.md).**

## Python

```python
point = (3, 4)
x, y = point
```

## Why

A fixed group of values, usually taken apart at once. [M35](../SATELLITE/M35-structured-bindings.md) names both halves: destructuring, and a capsule answering more than one value. Today it is a spacesuit with two fields.
