# PYTHON/M53 — generic classes and functions `class Box[T]`, `TypeVar`

**Introduced:** Python 3.5 / 3.12. Present in Python 3.12.
**Answer: satellite milestone [M31](../SATELLITE/M31-user-generics.md).**

## Python

```python
class Box[T]:
    def __init__(self, item: T): ...
def first[T](xs: list[T]) -> T: ...
```

## Why

[M31](../SATELLITE/M31-user-generics.md). The language's own containers are generic (`list<T>`, `map<K, V>`), and a program's spacesuits and capsules are not yet.
