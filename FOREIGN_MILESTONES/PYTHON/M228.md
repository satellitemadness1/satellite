# PYTHON/M228 — `clear()`, `copy()`, `reverse()`

**Introduced:** Python 1.0 / 3.3. Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
xs.clear()
ys = xs.copy()
xs.reverse()
```

## satellite

```
xs.clear()
satellite.container.list<satellite.variable.number> ys = xs
xs.reverse()
```

## What differs

`copy()` is plain assignment, because assignment copies.
