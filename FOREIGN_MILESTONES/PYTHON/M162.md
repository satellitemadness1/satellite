# PYTHON/M162 — `min()`, `max()`, `sum()`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
biggest = max(xs)
total = sum(xs)
```

## satellite

```
satellite.variable.number biggest = xs.max()
satellite.variable.number total = xs.sum()
```

## What differs

Methods on the list. Checked 2026-09-12: `sum()` of an empty list is `0`, and
`max()` of an empty list is `S0729`, the same as Python's `ValueError`. Two
numbers are `a.max(b)` and `a.min(b)`. A `key=` function is [M32](../SATELLITE/M32-capsules-as-values.md).
