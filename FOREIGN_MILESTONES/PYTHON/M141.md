# PYTHON/M141 — `asyncio` event loop, tasks and `gather`

**Introduced:** Python 3.4. Present in Python 3.12.
**Answer: satellite milestone [M43](../CXX26/M43.md).**

## Python

```python
results = await asyncio.gather(a(), b())
```

## satellite

```
satellite.variable.thread ta = satellite.thread.new(a())
satellite.variable.thread tb = satellite.thread.new(b())
ta.start()
tb.start()

satellite.variable.number rb = tb.join()
```

## What differs

**`gather` over two calls is two threads and two joins today**, and `join()` answers what the capsule returned. The event loop itself is [M43](../CXX26/M43.md).
