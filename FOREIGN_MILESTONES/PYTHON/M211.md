# PYTHON/M211 — `upper()`, `lower()`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
"héllo".upper()    # 'HÉLLO'
```

## satellite

```
s.upper()          // HéLLO
```

## What differs

Checked 2026-09-12: `"héllo".upper()` is `HéLLO`. **Only ASCII letters change**, silently. Python's is Unicode-aware. [M45](../CXX26/M45.md).
