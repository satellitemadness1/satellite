# PYTHON/M133 — exception groups and `except*`

**Introduced:** Python 3.11. Present in Python 3.12.
**Answer: satellite milestone [M33](../SATELLITE/M33-catching-a-refusal.md).**

## Python

```python
except* (OSError, ValueError) as group:
```

## Why

Several failures at once, usually from concurrent tasks. It needs [M33](../SATELLITE/M33-catching-a-refusal.md) for the failures and [M43](../CXX26/M43.md) for the tasks.
