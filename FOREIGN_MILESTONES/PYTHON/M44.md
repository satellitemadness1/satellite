# PYTHON/M44 — constants by convention and `typing.Final`

**Introduced:** Python 1.0 / 3.8. Present in Python 3.12.
**Answer: partial — satellite has part of it.**

## Python

```python
MAX_USERS: Final = 100
```

## satellite

```
satellite.library.max_users = 100
```

## What differs

A library value from a literal is resolved at parse time, which is the useful part. **Nothing stops a later assignment to it.** There is no `const` (the CXX23 folder's row 8), and a constant computed from others is [M34](../SATELLITE/M34-compile-time-evaluation.md).
