# PYTHON/M187 — `__call__`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: never.**

## Python

```python
def __call__(self, x): ...
```

## Why

Excluded by [M38](../SATELLITE/M38-operator-overloading.md). Passing behaviour around, which is why people write callable objects, is [M32](../SATELLITE/M32-capsules-as-values.md).
