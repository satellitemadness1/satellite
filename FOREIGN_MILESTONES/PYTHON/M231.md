**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite says it.**

## Python


## What differs

`keys()` and `values()` answer **lists**, in insertion order, not live views. There is no `items()`; walking keys and reading each value is the form. The two-name binding is [M35](../SATELLITE/M35-structured-bindings.md).
