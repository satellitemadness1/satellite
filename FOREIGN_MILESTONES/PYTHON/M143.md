# PYTHON/M143 — generator expressions

**Introduced:** Python 2.4. Present in Python 3.12.
**Answer: satellite milestone [M36](../SATELLITE/M36-ranges.md).**

## Python

```python
total = sum(x * x for x in xs)
```

## satellite

```
satellite.variable.number total = 0
satellite.statement.for (satellite.variable.number i = 0; i < xs.size(); i = i + 1)
{
    total = total + xs[i] * xs[i]
}
```
