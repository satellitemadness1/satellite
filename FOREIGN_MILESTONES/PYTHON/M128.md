# PYTHON/M128 — `raise`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M33](../SATELLITE/M33-catching-a-refusal.md).**

## Python

```python
raise ValueError("bad port")
```

## Why

**A program cannot refuse on purpose.** A refusal comes from the language, with a code, a caret and a call stack; there is no statement a program writes to stop itself with a message. `foreign.cpp` answers `raise ` with [M33](../SATELLITE/M33-catching-a-refusal.md), and [M42](../CXX26/M42.md) covers the checked-condition form.
