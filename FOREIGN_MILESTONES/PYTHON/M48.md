# PYTHON/M48 — `mypy` and static type checking

**Introduced:** Python 3.5 (PEP 484). Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
$ mypy app.py
```

## satellite

```
$ satl --check app.satl
```

## What differs

`--check` runs every pass and reports everything wrong with a file without running it. It is part of the one tool, not a second program.
