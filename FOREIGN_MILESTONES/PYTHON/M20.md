# PYTHON/M20 — duck typing

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: never.**

## Python

```python
def total(things):
    return sum(t.price() for t in things)   # anything with price()
```

## Why

**Every declaration names its type**, so a capsule takes a `widget` and not
"whatever has `price()`". The satellite version of *anything with `price()`* is
an interface that says so, which is [M31](../SATELLITE/M31-user-generics.md) plus the decision after it (row
[M182](M182.md), abstract base classes).

**But see row [M33](M33.md).** Checked 2026-09-12: a `number` variable accepted
a string assignment without a refusal, so the declared type is not yet enforced
everywhere it appears to be.
