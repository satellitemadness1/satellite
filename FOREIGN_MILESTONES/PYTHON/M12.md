# PYTHON/M12 — `lambda`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M32](../SATELLITE/M32-capsules-as-values.md).**

## Python

```python
names.sort(key=lambda n: n.lower())
```

## Why

[M32](../SATELLITE/M32-capsules-as-values.md). A capsule can be called and cannot be passed, so there is nothing for a
lambda to be. `list.sort_up(key)` already takes a key, which is the shape that
[M32](../SATELLITE/M32-capsules-as-values.md) generalises.
