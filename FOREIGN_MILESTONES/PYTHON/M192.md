# PYTHON/M192 — class decorators

**Introduced:** Python 2.6. Present in Python 3.12.
**Answer: satellite milestone [M32](../SATELLITE/M32-capsules-as-values.md).**

## Python

```python
@dataclass
class Point: ...
```

## Why

A decorator on a class needs the class to be a value and the decorator to be a function value. [M32](../SATELLITE/M32-capsules-as-values.md) for the second, [M41](../CXX26/M41.md) for the first.
