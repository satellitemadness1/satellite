# PYTHON/M276 — `sys.getsizeof()`

**Introduced:** Python 2.6. Present in Python 3.12.
**Answer: never.**

## Python

```python
sys.getsizeof(xs)
```

## satellite

```
satellite.system.memory.this.used("kb")
```

## What differs

A value's byte size is not visible (the CXX23 folder's `sizeof` row). The whole process's use is.
