# PYTHON/M119 — `enumerate()`

**Introduced:** Python 2.3. Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
for i, name in enumerate(names):
```

## satellite

```
satellite.statement.for (satellite.variable.number i = 0; i < names.size(); i = i + 1)
{
    satellite.variable.string name = names[i]
}
```

## What differs

The index loop is `enumerate`. The two-name binding is [M35](../SATELLITE/M35-structured-bindings.md).
