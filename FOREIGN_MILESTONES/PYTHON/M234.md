# PYTHON/M234 — map keys of other types

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: partial — satellite has part of it.**

## Python

```python
grid[(x, y)] = cell
```

## Why

**Strings and numbers work as keys today.** A tuple key needs [M35](../SATELLITE/M35-structured-bindings.md) and a spacesuit key needs [M38](../SATELLITE/M38-operator-overloading.md) (equality and hashing). A string key built with `+` (`x + "," + y`) is the workaround.
