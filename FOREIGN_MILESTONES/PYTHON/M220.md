# PYTHON/M220 — `encode()`, `decode()` and codecs

**Introduced:** Python 2.0 / 3.0. Present in Python 3.12.
**Answer: satellite milestone [M45](../CXX26/M45.md).**

## Python

```python
data = text.encode("utf-8")
```

## Why

A string is bytes with no declared encoding. Converting between encodings is [M45](../CXX26/M45.md).
