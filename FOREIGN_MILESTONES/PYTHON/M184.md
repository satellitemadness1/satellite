# PYTHON/M184 — `__eq__`, `__lt__`, `__hash__`

**Introduced:** Python 1.0 / 2.1. Present in Python 3.12.
**Answer: satellite milestone [M38](../SATELLITE/M38-operator-overloading.md).**

## Python

```python
def __eq__(self, other): ...
def __lt__(self, other): ...
```

## Why

[M38](../SATELLITE/M38-operator-overloading.md) limits user operators to `+`, `==` and `<`. It is also what lets a suit be sorted and used as a map key.
