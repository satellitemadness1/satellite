# PYTHON/M194 — `@dataclass`

**Introduced:** Python 3.7. Present in Python 3.12.
**Answer: partial — satellite has part of it.**

## Python

```python
@dataclass
class Point:
    x: int = 0
    y: int = 0
```

## satellite

```
satellite.spacesuit point()
{
    satellite.protected
    {
        satellite.variable.number x = 0
        satellite.variable.number y = 0
    }
}
```

## What differs

**The field list is the same, and a spacesuit displays itself** (`<point x: 0 y:
0>`-style, row [M183](M183.md)). What `@dataclass` generates and a suit does not:

- `__init__(x, y)`: constructor arguments are open (row [M170](M170.md))
- `__eq__` and ordering: [M38](../SATELLITE/M38-operator-overloading.md)
- public field access: never (row [M172](M172.md)), so a getter per field
