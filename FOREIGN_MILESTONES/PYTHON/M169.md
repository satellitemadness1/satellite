# PYTHON/M169 — `help()` and `dir()`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: partial — satellite has part of it.**

## Python

```python
help(str.split)
dir(obj)
```

## satellite

```
satellite.help(satellite.variable.string.split)
$ satl --words satellite.variable.string
```

## What differs

**The language's own paths are richly documented from inside a program and from the shell.** `satellite.help(path)` prints what one does with an example, and `satl --words <path>` lists its children. A program's own capsules and suits are not described by either (row [M23](M23.md)).
