# PYTHON/M315 — `queue.Queue`

**Introduced:** Python 2.3. Present in Python 3.12.
**Answer: satellite milestone [M40](../SATELLITE/M40-locks-and-atomics.md).**

## Python

```python
q = queue.Queue()
q.put(item)
```

## Why

A thread-safe queue needs [M40](../SATELLITE/M40-locks-and-atomics.md)'s lock, and the list is not safe to share across threads today.
