# PYTHON/M64 — `complex` and `1j`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: never.**

## Python

```python
z = 3 + 4j
```

## Why

Not a language type in satellite. A spacesuit with two numbers is the satellite version, and [M38](../SATELLITE/M38-operator-overloading.md) would give it `+`. The CXX23 folder answers `std::complex` the same way.
