# PYTHON/M130 — `try … except … else`

**Introduced:** Python 2.5. Present in Python 3.12.
**Answer: satellite milestone [M33](../SATELLITE/M33-catching-a-refusal.md).**

## Python

```python
try:
    n = int(text)
except ValueError:
    n = 0
else:
    log(n)
```

## Why

The `else` branch runs when nothing was raised. It follows [M33](../SATELLITE/M33-catching-a-refusal.md).
