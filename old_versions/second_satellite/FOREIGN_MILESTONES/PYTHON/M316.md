# PYTHON/M316 — `concurrent.futures` and thread pools

**Introduced:** Python 3.2. Present in Python 3.12.
**Answer: satellite milestone [M43](../CXX26/M43.md).**

## Python

```python
with ThreadPoolExecutor(8) as ex:
    results = list(ex.map(work, items))
```

## Why

The interpreter keeps a worker pool of its own with no door to it from a program. Composing parallel work is [M43](../CXX26/M43.md), which must follow [M40](../SATELLITE/M40-locks-and-atomics.md). N threads and N joins is the spelling today.
