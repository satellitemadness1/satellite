# PYTHON/M122 — `for … else` and `while … else`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M27](../SATELLITE/M27-break-and-continue.md).**

## Python

```python
for x in xs:
    if bad(x): break
else:
    print("all good")
```

## Why

The `else` runs when the loop did **not** `break`, so it means nothing without `break` (M27). When [M27](../SATELLITE/M27-break-and-continue.md) lands, whether satellite adopts the `else` form is a separate decision; a bool set before the `break` is the portable spelling.
