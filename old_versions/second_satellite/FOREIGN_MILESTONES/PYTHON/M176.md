# PYTHON/M176 — `@classmethod` and alternative constructors

**Introduced:** Python 2.2. Present in Python 3.12.
**Answer: partial — satellite has part of it.**

## Python

```python
@classmethod
def from_string(cls, s): ...
```

## satellite

```
satellite.capsule point_from_string(satellite.variable.string s) satellite.returns(point)
{
    point p
    satellite.return(p)
}
```

## What differs

Checked 2026-09-12: **a file-scope capsule can build a spacesuit and answer it**, and the caller's handle works. That is the factory half of `@classmethod`. What is missing is `cls`, a class as a value, which would need [M41](../CXX26/M41.md).
