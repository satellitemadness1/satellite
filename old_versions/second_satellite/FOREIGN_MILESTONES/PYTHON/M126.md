# PYTHON/M126 — `match` mapping patterns and `case _`

**Introduced:** Python 3.10. Present in Python 3.12.
**Answer: satellite milestone [M30](../SATELLITE/M30-switch-and-match.md).**

## Python

```python
case {"action": "go", "speed": s}: ...
case _: ...
```

## Why

`case _` is [M30](../SATELLITE/M30-switch-and-match.md)'s default. Mapping patterns ask a map for keys and bind the values, which is [M30](../SATELLITE/M30-switch-and-match.md) plus [M35](../SATELLITE/M35-structured-bindings.md).
