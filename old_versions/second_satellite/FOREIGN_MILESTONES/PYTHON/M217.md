# PYTHON/M217 — `startswith()`, `endswith()`, `in`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
path.startswith("/")
"err" in line
```

## satellite

```
path.starts_with("/")
line.contains("err")
```

## What differs

The same questions with underscores. Python's tuple argument (`startswith(("a", "b"))`) is two calls.
