# PYTHON/M281 — `read()`, `readline()`, `write()`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
text = f.read()
line = f.readline()
f.write("no newline")
```

## satellite

```
satellite.variable.string text = f.read_all()
satellite.variable.string line = f.read_line()
f.write("no newline")
f.write_line("with newline")
```

## What differs

`write` adds nothing; `write_line` adds the newline. Both answer whether the write worked.
