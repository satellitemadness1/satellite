# PYTHON/M129 — `try … finally`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M33](../SATELLITE/M33-catching-a-refusal.md).**

## Python

```python
f = open(path)
try:
    process(f)
finally:
    f.close()
```

## satellite

```
satellite.variable.file f = satellite.file.open(path, "read")
process(f)
f.close()
```

## What differs

With no way to catch a refusal, there is also no cleanup that runs *because of* one: a refusal ends the whole run. `finally` belongs to [M33](../SATELLITE/M33-catching-a-refusal.md)'s design.
