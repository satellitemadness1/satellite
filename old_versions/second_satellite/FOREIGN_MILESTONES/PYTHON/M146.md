# PYTHON/M146 — `itertools`

**Introduced:** Python 2.3. Present in Python 3.12.
**Answer: satellite milestone [M36](../SATELLITE/M36-ranges.md).**

## Python

```python
from itertools import chain, groupby, islice, product
```

## Why

The finite tools (`chain`, `product`, `groupby`, `accumulate`) are [M36](../SATELLITE/M36-ranges.md) pipelines. The infinite ones (`count`, `cycle`, `repeat`) are lazy and are not planned.
