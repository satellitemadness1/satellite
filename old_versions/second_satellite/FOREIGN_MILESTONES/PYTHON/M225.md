# PYTHON/M225 — `list.remove(x)`, `del xs[i]`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
xs.remove(1)
del xs[0]
```

## satellite

```
xs.remove(1)
xs.remove_at(0)
```

## What differs

Checked 2026-09-12: `remove(x)` removes the **first** match, as Python's does, and removing a value that is not there is `S0728` (Python's `ValueError`).
