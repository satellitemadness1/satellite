# PYTHON/M97 — `and` / `or` answering an operand, `x or default`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: never.**

## Python

```python
name = given or "anonymous"
```

## satellite

```
satellite.variable.string name = given
satellite.statement.if (given.empty()) { name = "anonymous" }
```

## What differs

Python's `or` answers one of its operands, which only works because every value has a truth value. Satellite has no truthiness (next row), so [M28](../SATELLITE/M28-logical-operators.md)'s `||` will answer a bool.
