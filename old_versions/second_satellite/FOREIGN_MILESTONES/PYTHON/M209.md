# PYTHON/M209 — `len(s)`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
len("héllo")     # 5
```

## satellite

```
satellite.variable.string s = "héllo"
satellite.console.display(s.size())    // 6
```

## What differs

`size()` counts **bytes**. Checked 2026-09-12: `"héllo".size()` is `6`, because `é` is two bytes in UTF-8. Python counts code points and says `5`. What a character is, is [M45](../CXX26/M45.md).
