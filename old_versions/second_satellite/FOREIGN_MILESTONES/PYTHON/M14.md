# PYTHON/M14 — `match` statement

**Introduced:** Python 3.10. Present in Python 3.12.
**Answer: satellite milestone [M30](../SATELLITE/M30-switch-and-match.md).**

## Python

```python
match command:
    case "go": go()
    case "stop": stop()
    case _: unknown()
```

## Why

[M30](../SATELLITE/M30-switch-and-match.md), and Python's `match` is **structural** pattern matching, which is more than
[M30](../SATELLITE/M30-switch-and-match.md)'s `switch`. Rows [M124](M124.md) to [M126](M126.md) take the parts apart.
Today it is an `else if` chain.
