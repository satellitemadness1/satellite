# PYTHON/M265 — `multiprocessing`

**Introduced:** Python 2.6. Present in Python 3.12.
**Answer: open — no milestone and no refusal yet; this needs a decision.**

## Python

```python
with Pool(4) as p:
    p.map(work, items)
```

## Why

Follows `subprocess`: no second process can be started. **Threads in satellite run in parallel**, so Python's reason for `multiprocessing`, the GIL, does not apply (row [M312](M312.md)).
