# PYTHON/M24 — line continuation `\` and inside brackets

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: partial — satellite has part of it.**

## Python

```python
total = first + \
        second
total = (first +
         second)
```

## satellite

```
satellite.variable.number total = (first +
    second)
```

## What differs

Checked 2026-09-12: **inside parentheses an expression may continue onto the
next line** (`(1 +` then `2)` printed `3`). **A backslash at the end of a line is
refused** (`S0231`).
