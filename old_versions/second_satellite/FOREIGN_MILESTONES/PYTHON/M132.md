# PYTHON/M132 — `raise … from` and exception chaining

**Introduced:** Python 3.0. Present in Python 3.12.
**Answer: satellite milestone [M33](../SATELLITE/M33-catching-a-refusal.md).**

## Python

```python
raise ConfigError("bad file") from err
```

## Why

Carrying a cause inside a refusal. Before [M33](../SATELLITE/M33-catching-a-refusal.md) there is no refusal value to carry one.
