# PYTHON/M38 — `del name`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: never.**

## Python

```python
del big_table
```

## satellite

```
big_table.clear()
```

## What differs

A name lasts until its block ends and cannot be removed early. `clear()` empties a list, map, string or variant, and a spacesuit is freed when its last handle goes.
