# PYTHON/M154 — returning several values `return a, b`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M35](../SATELLITE/M35-structured-bindings.md).**

## Python

```python
def span(xs):
    return min(xs), max(xs)
```

## Why

A capsule answers exactly one value. [M35](../SATELLITE/M35-structured-bindings.md) names *a capsule answering more than one value*. Today the answer is a small spacesuit, or two capsules.
