# PYTHON/M166 — the mutable default argument trap

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: never.**

## Python

```python
def add(x, into=[]):   # one list shared by every call
```

## Why

Cannot happen: there are no default arguments yet (M39), and a list is copied rather than shared. When [M39](../SATELLITE/M39-overloading-and-defaults.md) lands, a default that is a fresh value per call is the behaviour to keep.
