# PYTHON/M80 — `ord()` and `chr()`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: open — no milestone and no refusal yet; this needs a decision.**

## Python

```python
ord("A")   # 65
chr(65)    # 'A'
```

## Why

**Not in `satl --words`.** There is no character type and no byte-to-number conversion on a string. Open, and it waits on [M45](../CXX26/M45.md) for what a *character* is beyond ASCII.
