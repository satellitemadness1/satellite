# PYTHON/M131 — custom exception classes

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M33](../SATELLITE/M33-catching-a-refusal.md).**

## Python

```python
class ConfigError(Exception): ...
```

## Why

[M33](../SATELLITE/M33-catching-a-refusal.md) is deliberately an *answer-or-refusal value* (C++23's `std::expected`) rather than a hierarchy caught by type. A Python reader should expect to inspect a refusal, not to catch it by class.
