# PYTHON/M11 — `break` / `continue`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M27](../SATELLITE/M27-break-and-continue.md).**

## Python

```python
for line in lines:
    if not line:
        continue
    if line == "END":
        break
```

## satellite

```
// until M27: move the loop into its own capsule and return out of it
```

## What differs

[M27](../SATELLITE/M27-break-and-continue.md). **The cleanest workaround is `satellite.return` from inside the loop**, in
a capsule of its own; the CXX23 folder checked that a `return` inside a `for`
answers immediately ([CXX23 row 148](../CXX23/M148.md)). `continue` becomes an
`if` around the rest of the body.
