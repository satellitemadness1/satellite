# PYTHON/M163 — `any()` and `all()`

**Introduced:** Python 2.5. Present in Python 3.12.
**Answer: satellite milestone [M32](../SATELLITE/M32-capsules-as-values.md).**

## Python

```python
if any(x < 0 for x in xs):
```

## satellite

```
satellite.statement.if (xs.contains(0)) { ... }
```

## What differs

They take a condition, so [M32](../SATELLITE/M32-capsules-as-values.md). **`contains(x)` is `any` for one exact value.**
