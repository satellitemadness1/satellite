# PYTHON/M15 — list comprehensions

**Introduced:** Python 2.0. Present in Python 3.12.
**Answer: satellite milestone [M36](../SATELLITE/M36-ranges.md).**

## Python

```python
squares = [x * x for x in xs if x > 0]
```

## satellite

```

{
    satellite.variable.number x = xs[i]
```

## What differs

[M36](../SATELLITE/M36-ranges.md), which names list comprehensions among its foreign spellings and is eager,
which is what a comprehension is. [M36](../SATELLITE/M36-ranges.md) depends on [M32](../SATELLITE/M32-capsules-as-values.md), since a pipeline is made of
functions passed along.

**The syntax is still a decision.** [M36](../SATELLITE/M36-ranges.md)'s pipeline is method-shaped. Whether
satellite ever has the bracketed Python form is not recorded anywhere, and
square brackets already mean subscripts and slices.
