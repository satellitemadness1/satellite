# PYTHON/M124 — `match` with class and sequence patterns

**Introduced:** Python 3.10. Present in Python 3.12.
**Answer: satellite milestone [M30](../SATELLITE/M30-switch-and-match.md).**

## Python

```python
match shape:
    case Point(x=0, y=0): ...
    case [first, *rest]: ...
```

## Why

Destructuring inside a case needs [M30](../SATELLITE/M30-switch-and-match.md) and [M35](../SATELLITE/M35-structured-bindings.md) together. Class patterns also need a way to ask a suit what it is (row [M60](M60.md)).
