# PYTHON/M215 — `replace()`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
"a-b-c".replace("-", "+")
```

## satellite

```
s.replace("-", "+")
```

## What differs

Checked 2026-09-12: every occurrence is replaced and `s` itself is unchanged, as in Python. There is no `count` argument.
