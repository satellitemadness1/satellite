# PYTHON/M40 — chained assignment `a = b = 0`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: never.**

## Python

```python
a = b = 0
```

## satellite

```
a = 0
b = 0
```

## What differs

Checked 2026-09-12: `S0203` at the second `=`. Assignment is a statement and not an expression, so it has no value to pass along.
