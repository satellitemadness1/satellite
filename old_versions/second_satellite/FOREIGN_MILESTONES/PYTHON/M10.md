# PYTHON/M10 — `and` / `or` / `not`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M28](../SATELLITE/M28-logical-operators.md).**

## Python

```python
if x > 0 and not done:
```

## satellite

```
satellite.statement.if (x > 0)
{
    satellite.statement.if (!done) { ... }
}
```

## What differs

**`not` already exists, spelled `!`.** Checked 2026-09-12: `!ready` and
`!l.empty()` both work. The words `and`, `or` and `not` are all refused
(`S0201`), and so are `&&` and `||`. **`and` and `or` are [M28](../SATELLITE/M28-logical-operators.md).** Until then, nest
two ifs; for `or`, set a bool in each branch and test it.

The first version of this row sent all three to [M28](../SATELLITE/M28-logical-operators.md). `!` is not missing.
