# PYTHON/M120 — `zip()`

**Introduced:** Python 2.0. Present in Python 3.12.
**Answer: satellite milestone [M36](../SATELLITE/M36-ranges.md).**

## Python

```python
for name, age in zip(names, ages):
```

## satellite

```
satellite.statement.for (satellite.variable.number i = 0; i < names.size(); i = i + 1)
{
    satellite.variable.string name = names[i]
    satellite.variable.number age = ages[i]
}
```

## What differs

[M36](../SATELLITE/M36-ranges.md) (which lists C++23's `views::zip`). One index over two lists works today; Python's `zip` stops at the shorter list, so check both sizes.
