# PYTHON/M17 — decorators

**Introduced:** Python 2.4. Present in Python 3.12.
**Answer: satellite milestone [M32](../SATELLITE/M32-capsules-as-values.md).**

## Python

```python
@lru_cache
def fib(n): ...
```

## Why

[M32](../SATELLITE/M32-capsules-as-values.md). A decorator is a function that takes a function and hands one back, so it
needs a capsule to be a value first. `foreign.cpp` answers `@` with the same
number. Class decorators and `@property` are separate rows
([M192](M192.md), [M174](M174.md)).
