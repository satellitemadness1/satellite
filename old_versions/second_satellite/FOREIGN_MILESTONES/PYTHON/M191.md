# PYTHON/M191 — metaclasses, `__init_subclass__`, `__class_getitem__`

**Introduced:** Python 2.2 / 3.6 / 3.7. Present in Python 3.12.
**Answer: never.**

## Python

```python
class Meta(type): ...
class Model(metaclass=Meta): ...
```

## Why

A class is not a value, so there is no class-of-a-class. What metaclasses are usually used for, registering or checking every subclass, is [M41](../CXX26/M41.md).
