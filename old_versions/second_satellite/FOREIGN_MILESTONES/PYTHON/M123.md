# PYTHON/M123 — `return` from inside a loop

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
for x in xs:
    if x == target:
        return True
```

## satellite

```
satellite.statement.for (satellite.variable.number i = 0; i < xs.size(); i = i + 1)
{
    satellite.statement.if (xs[i] == target) { satellite.return(satellite.bool.true) }
}
```

## What differs

Checked in the CXX23 folder. **It is the workaround for `break`** until [M27](../SATELLITE/M27-break-and-continue.md).
