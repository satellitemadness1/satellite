# PYTHON/M155 — functions as values and passing a function

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M32](../SATELLITE/M32-capsules-as-values.md).**

## Python

```python
def apply(f, x):
    return f(x)
apply(len, "abc")
```

[M32](../SATELLITE/M32-capsules-as-values.md).
