# PYTHON/M171 — attributes added at run time `obj.extra = 1`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: never.**

## Python

```python
p.label = "origin"      # a new attribute, from outside
```

## Why

A suit's fields are the ones declared in it. The object's shape is fixed by its declaration, which is also why `__slots__` has nothing to do (row [M190](M190.md)).
