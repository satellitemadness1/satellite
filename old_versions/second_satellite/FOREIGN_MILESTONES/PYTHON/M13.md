# PYTHON/M13 — `try` / `except`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M33](../SATELLITE/M33-catching-a-refusal.md).**

## Python

```python
try:
    n = int(text)
except ValueError:
    n = 0
```

## What differs

[M33](../SATELLITE/M33-catching-a-refusal.md). **A refusal stops the run and cannot be caught.** Python's habit, *easier to
ask forgiveness than permission*, is the one that does not transfer: satellite is
built for *look before you leap*, and the refusals say which question to ask
first (`S0726` names `has(k)`, `S0716` and `S0728` name `contains(x)`, `S0729`
names `empty()`).

The one exception to asking first is `"abc".to_number()`, which refuses with
`S0610` and has no question to ask beforehand. See row [M78](M78.md).
