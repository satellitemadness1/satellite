# PYTHON/M161 — `sorted()` and `list.sort(key=…, reverse=…)`

**Introduced:** Python 2.4. Present in Python 3.12.
**Answer: partial — satellite has part of it.**

## Python

```python
xs.sort(reverse=True)
people.sort(key=lambda p: p.age)
```

## satellite

```
xs.sort("down")
xs.sort_up(key)
```

## What differs

`sort()`, `sort("down")`, `sort_up(key)` and `sort_down(key)` sort **in place**.
`satellite.help` says strings sort as text and numbers as numbers. **A key
function is [M32](../SATELLITE/M32-capsules-as-values.md)**, and sorting spacesuits by their own `<` is [M38](../SATELLITE/M38-operator-overloading.md). `sorted()`,
which answers a new list, is assignment (a copy) followed by `sort()`.
