# PYTHON/M25 — semicolons and several statements on one line

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: never.**

## Python

```python
a = 1; b = 2
```

## satellite

```
a = 1
b = 2
```

## What differs

A statement ends at the end of its line. Checked 2026-09-12: a trailing `;` is `S0203`, and the message says to put the second statement on its own line.
