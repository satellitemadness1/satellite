# PYTHON/M139 — `async def` and `await`

**Introduced:** Python 3.5. Present in Python 3.12.
**Answer: satellite milestone [M43](../CXX26/M43.md).**

## Python

```python
async def fetch(url):
    return await client.get(url)
```

## Why

Composing concurrent work is [M43](../CXX26/M43.md), and [M43](../CXX26/M43.md) must not start before [M40](../SATELLITE/M40-locks-and-atomics.md). Satellite's concurrency today is threads (row [M310](M310.md)).
