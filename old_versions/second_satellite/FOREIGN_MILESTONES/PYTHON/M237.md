# PYTHON/M237 — `collections.deque`

**Introduced:** Python 2.4. Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
q = deque()
q.appendleft(x)
q.popleft()
```

## satellite

```
q.insert(0, x)
q.remove_first()
```

## What differs

One list does both ends. The cost at the front has not been measured.
