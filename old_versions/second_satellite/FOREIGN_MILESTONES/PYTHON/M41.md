# PYTHON/M41 — tuple unpacking and swapping `a, b = b, a`

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite milestone [M35](../SATELLITE/M35-structured-bindings.md).**

## Python

```python
a, b = b, a
q, r = divmod(7, 2)
```

## satellite

```
satellite.variable.number spare = a
a = b
b = spare
```

## What differs

Checked 2026-09-12: `a, b = b, a` is `S0203` at the comma. Taking a value apart in one line is [M35](../SATELLITE/M35-structured-bindings.md), whose page names Python's `a, b =` among its spellings.
