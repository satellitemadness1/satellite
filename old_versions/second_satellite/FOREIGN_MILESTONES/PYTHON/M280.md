# PYTHON/M280 — a file that is not there

**Introduced:** Python 1.0. Present in Python 3.12.
**Answer: satellite says it.**

## Python

```python
try:
    f = open(path)
except FileNotFoundError: ...
```

## satellite

```
satellite.variable.file f = satellite.file.open(path, "read")
satellite.statement.if (f.ok() == satellite.bool.false)
{
    satellite.console.display(f.error())
}
```

## What differs

**No exception and no refusal.** Checked 2026-09-12: opening `/nonexistent/zz` answered `ok()` `false` and `error()` `No such file or directory`. [M33](../SATELLITE/M33-catching-a-refusal.md) names this as the pattern to generalise.
