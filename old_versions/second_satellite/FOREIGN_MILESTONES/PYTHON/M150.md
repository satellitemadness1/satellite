# PYTHON/M150 — keyword-only `*` and positional-only `/` parameters

**Introduced:** Python 3.0 / 3.8. Present in Python 3.12.
**Answer: satellite milestone [M39](../SATELLITE/M39-overloading-and-defaults.md).**

## Python

```python
def f(a, /, b, *, c): ...
```

## Why

These only mean something once keyword arguments exist, so they follow [M39](../SATELLITE/M39-overloading-and-defaults.md).
