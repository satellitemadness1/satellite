# PYTHON/M29 — source encoding and `# -*- coding: -*-`

**Introduced:** Python 2.3. Present in Python 3.12.
**Answer: satellite milestone [M45](../CXX26/M45.md).**

## Python

```python
# -*- coding: latin-1 -*-
```

## Why

A satellite string is bytes with no declared encoding, and a source file is read the same way. Declaring what the bytes mean is [M45](../CXX26/M45.md).
