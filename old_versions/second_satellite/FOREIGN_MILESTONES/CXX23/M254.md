# CXX23/M254 — `std::erase`, `std::erase_if`

**Introduced:** C++20. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
std::erase(v, 0);
std::erase_if(v, is_blank);
```

## satellite

```
v.remove(0)
```

## What differs

`remove(x)` covers erasing by value (whether it removes every match or only the first has not been checked here). `erase_if` takes a predicate, so it is [M32](../SATELLITE/M32-capsules-as-values.md).
