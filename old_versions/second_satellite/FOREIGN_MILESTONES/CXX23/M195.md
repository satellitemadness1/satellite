# CXX23/M195 — abbreviated function templates `void f(auto x)`

**Introduced:** C++20. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
void print(auto value);
```

## Why

Every parameter names its type. A capsule over any type is [M31](../SATELLITE/M31-user-generics.md), spelled with a type parameter.
