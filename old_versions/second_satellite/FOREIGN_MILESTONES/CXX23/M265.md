# CXX23/M265 — `std::sort` with a comparator, `std::stable_sort`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
std::sort(v.begin(), v.end(), [](auto &a, auto &b) { return a.age < b.age; });
```

## satellite

```
v.sort_up(key)
```

## What differs

`sort()`, `sort(direction)`, `sort_up(key)` and `sort_down(key)` exist. A
comparator *function* is [M32](../SATELLITE/M32-capsules-as-values.md), and sorting spacesuits by their own `<` is [M38](../SATELLITE/M38-operator-overloading.md).
Whether `sort` is stable has not been checked, so rely on it only after asking
`satellite.help`.
