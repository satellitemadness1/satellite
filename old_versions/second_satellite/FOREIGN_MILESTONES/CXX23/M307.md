# CXX23/M307 — `std::shared_mutex`, `std::scoped_lock`

**Introduced:** C++17. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M40](../SATELLITE/M40-locks-and-atomics.md).**

## C++

```cpp
std::scoped_lock both(a_mutex, b_mutex);
```

## Why

[M40](../SATELLITE/M40-locks-and-atomics.md). Its third option, containers that refuse when shared across threads, is what would make reader-writer locks rarely needed.
