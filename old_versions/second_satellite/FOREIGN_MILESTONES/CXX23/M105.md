# CXX23/M105 — `static_cast` and numeric/string conversions

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
int n = std::stoi(s);
std::string t = std::to_string(n);
double d = static_cast<double>(n);
```

## satellite

```
satellite.variable.number n = s.to_number()
satellite.variable.string t = n.to_string()
satellite.variable.float d = n
```

## What differs

Checked 2026-09-12: all three work. `satellite.variable.string s = n` also
converts a number on assignment, and `+` joins a number onto a string. Those are
the two implicit conversions to know about. Methods on a call's *answer* still
refuse (`s.to_number().round()` is S0720, see [M29](../SATELLITE/M29-method-chaining.md)).
