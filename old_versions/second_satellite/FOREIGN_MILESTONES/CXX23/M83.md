# CXX23/M83 — `char8_t` and `u8""` literals

**Introduced:** C++20. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M45](../CXX26/M45.md).**

## C++

```cpp
const char8_t *s = u8"text";
```

## Why

Same as the wide types: the encoding of a satellite string is not declared yet, and [M45](../CXX26/M45.md) is that decision.
