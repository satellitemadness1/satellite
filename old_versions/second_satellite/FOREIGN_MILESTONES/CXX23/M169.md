# CXX23/M169 — inheriting constructors `using Base::Base`

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: open — no milestone and no refusal yet; this needs a decision.**

## C++

```cpp
struct Derived : Base { using Base::Base; };
```

## Why

Follows [M27](M27.md) and [M28](M28.md). A suit holds a copy of its superclass and gets its field defaults. Arguments would have to exist first.
