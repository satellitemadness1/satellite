# CXX23/M302 — `system_clock::now()` and subtracting two times

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
auto elapsed = std::chrono::system_clock::now() - start;
```

## Why

`satellite.time.now` gives an instant, and today an instant can only be
displayed. Subtracting two, and whether the result is a number of seconds or a
`duration`, is **PLAN.md's [M29](../SATELLITE/M29-method-chaining.md) (the calendar)**. That is a build milestone in the
plan's own numbering, not a promise from this folder.
