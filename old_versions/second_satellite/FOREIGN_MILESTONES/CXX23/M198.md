# CXX23/M198 — CRTP

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
struct Derived : Base<Derived> { };
```

## Why

The curiously recurring template pattern gets static dispatch out of templates. It needs [M31](../SATELLITE/M31-user-generics.md) and a use for static dispatch, and satellite has no compile-time dispatch to want.
