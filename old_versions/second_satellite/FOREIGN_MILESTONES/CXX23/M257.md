# CXX23/M257 — `reserve`, `capacity`, `shrink_to_fit`

**Introduced:** C++98 / C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
v.reserve(1000);
```

## satellite

```
v.reserve(1000)
```

## What differs

`reserve(n)` exists as a capacity hint, and `list_methods.cpp` notes that it keeps the hint honest under copy-on-write. There is no `capacity()` to read back and no `shrink_to_fit`.
