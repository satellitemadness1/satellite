# CXX23/M58 — function-like macros

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
#define SQUARE(x) ((x) * (x))
```

## satellite

```
satellite.capsule square(satellite.variable.number x) satellite.returns(satellite.variable.number)
{
    satellite.return(x * x)
}
```

## What differs

**There is no preprocessor, so nothing rewrites source text before it is
parsed.** Write a capsule. It has a type, it evaluates its argument once, and a
refusal inside it has a line number, none of which a macro gives you.
