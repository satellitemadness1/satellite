# CXX23/M237 — `toupper`, `tolower`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
std::transform(s.begin(), s.end(), s.begin(), ::toupper);
```

## satellite

```
satellite.variable.string loud = s.upper()
```

## What differs

`upper()` and `lower()` convert the whole string. Only ASCII changes: strings are bytes, and [M45](../CXX26/M45.md) records that `upper()` on anything else does nothing, silently.
