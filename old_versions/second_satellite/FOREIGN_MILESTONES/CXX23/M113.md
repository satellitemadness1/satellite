# CXX23/M113 — uninitialised variables

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
int n;            // indeterminate
std::cout << n;   // undefined
```

## satellite

```
satellite.variable.number n
satellite.console.display(n)     // nothing
```

## What differs

**A declaration with no value holds nothing, not garbage.** Checked 2026-09-12.
The C++ bug, reading memory nobody wrote, is not expressible.
