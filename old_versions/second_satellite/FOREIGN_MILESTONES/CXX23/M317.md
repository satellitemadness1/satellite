# CXX23/M317 — `FILE *`, `fopen`, `fgets`, `fclose`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
FILE *f = fopen(path, "r"); fgets(line, 256, f); fclose(f);
```

## satellite

```
satellite.variable.file f = satellite.file.open(path, "read")
satellite.variable.string line = f.read_line()
f.close()
```

## What differs

Closing is explicit (`foreign.cpp` on Python's `with`: *there is no scope guard*). Check `f.ok()` after opening.
