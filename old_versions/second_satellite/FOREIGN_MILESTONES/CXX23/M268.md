# CXX23/M268 — `std::remove_if` and the erase–remove idiom

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M32](../SATELLITE/M32-capsules-as-values.md).**

## C++

```cpp
v.erase(std::remove_if(v.begin(), v.end(), bad), v.end());
```

## Why

Takes a predicate, so [M32](../SATELLITE/M32-capsules-as-values.md). Satellite has no erase-remove idiom to learn, because `remove(x)` and `remove_at(n)` change the list directly.
