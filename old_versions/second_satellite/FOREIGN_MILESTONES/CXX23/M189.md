# CXX23/M189 — alias templates

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M31](../SATELLITE/M31-user-generics.md).**

## C++

```cpp
template <typename T> using Grid = std::vector<std::vector<T>>;
```

## Why

Needs [M31](../SATELLITE/M31-user-generics.md), and it is the generic form of the type-alias question, which is open (see `typedef`).
