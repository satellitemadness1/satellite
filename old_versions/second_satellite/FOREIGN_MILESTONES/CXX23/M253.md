# CXX23/M253 — `insert` and `erase` at a position

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
v.insert(v.begin() + n, x);
v.erase(v.begin() + n);
```

## satellite

```
v.insert(n, x)
v.remove_at(n)
```

## What differs

An index instead of an iterator. `remove(x)` removes by value.
