# CXX23/M315 — `setjmp` and `longjmp`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
if (setjmp(env) == 0) { longjmp(env, 1); }
```

## Why

A non-local jump is `goto` across frames ([M23](M23.md): never). Recovering from failure is [M33](../SATELLITE/M33-catching-a-refusal.md).
