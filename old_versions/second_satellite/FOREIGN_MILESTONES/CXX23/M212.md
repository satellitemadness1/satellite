# CXX23/M212 — `std::terminate`, `std::abort`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
std::terminate();
```

## Why

**A refusal stops the run**, with a code, a caret and a call stack. **What is
missing is a program refusing on purpose.** `foreign.cpp` tells a Rust reader
about `panic!`: *there is no way to raise one on purpose yet*. [M42](../CXX26/M42.md) covers
the checked-condition form. A bare "stop here, with this message" has no
milestone.
