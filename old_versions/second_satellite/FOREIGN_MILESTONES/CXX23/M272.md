# CXX23/M272 — `std::copy`, `std::copy_if`

**Introduced:** C++98 / C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
std::copy(a.begin(), a.end(), std::back_inserter(b));
```

## satellite

```
satellite.container.list<satellite.variable.number> b = a
```

## What differs

Assigning a list copies it (checked 2026-09-12). `copy_if` needs a predicate, which is [M32](../SATELLITE/M32-capsules-as-values.md).
