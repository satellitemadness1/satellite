# CXX23/M314 — `printf` and `scanf`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
printf("%d\n", x);
scanf("%d", &x);
```

## satellite

```
satellite.console.display(x)
satellite.variable.number x = satellite.console.input()
```

## What differs

No format string ([M3](M3.md), [M50](M50.md)). `foreign.cpp` already answers `printf(`.
