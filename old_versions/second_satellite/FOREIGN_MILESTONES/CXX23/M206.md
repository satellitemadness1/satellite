# CXX23/M206 — `std::move_only_function`

**Introduced:** C++23. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M32](../SATELLITE/M32-capsules-as-values.md).**

## C++

```cpp
std::move_only_function<void()> task;
```

## Why

A callable value (M32). The move-only half does not apply, because nothing in satellite is move-only.
