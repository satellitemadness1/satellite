# CXX23/M193 — non-type template parameters, `auto` template parameters

**Introduced:** C++98 / C++17. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M31](../SATELLITE/M31-user-generics.md).**

## C++

```cpp
template <std::size_t N> struct Buffer { };
```

## Why

Follows [M31](../SATELLITE/M31-user-generics.md). With no fixed-size containers, the common use (a length in the type) has less to do here.
