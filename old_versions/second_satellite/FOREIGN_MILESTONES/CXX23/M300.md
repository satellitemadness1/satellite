# CXX23/M300 — `std::osyncstream`: output from several threads

**Introduced:** C++20. Present in C++23 (ISO/IEC 14882:2024).
**Answer: open — no milestone and no refusal yet; this needs a decision.**

## C++

```cpp
std::osyncstream(std::cout) << "line\n";
```

## Why

Whether two threads calling `satellite.console.display` at once can interleave within a line has not been checked here. `satellite_console/console.cpp` does lock, so the answer may already be *says it*. Open until measured, next to [M40](../SATELLITE/M40-locks-and-atomics.md).
