# CXX23/M153 — global variables

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
int counter = 5;
int main() { ++counter; }
```

## satellite

```
satellite.library.counter = 5

satellite.capsule satellite.main()
{
    satellite.library.counter = satellite.library.counter + 1
}
```

## What differs

Checked 2026-09-12: printed `6`. **A global is always written with its full
path**, so every use of shared state is visible where it happens. The
library's thread behaviour is covered in [M40](../SATELLITE/M40-locks-and-atomics.md), and the folder currently
contradicts itself about it. That is worth settling there, not here.
