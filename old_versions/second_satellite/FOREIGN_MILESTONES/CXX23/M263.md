# CXX23/M263 — `std::min_element`, `std::max_element`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
auto it = std::max_element(v.begin(), v.end());
```

## satellite

```
satellite.variable.number biggest = v.max()
```

## What differs

Answers the value, not a position. Use `index_of` on the answer for the position.
