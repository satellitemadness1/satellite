# CXX23/M137 — member access `.`, `->`, `.*`, `->*`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
p->method();
(obj.*member)();
```

## satellite

```
p.call_method()
```

## What differs

A spacesuit is a reference already, so access is always a dot. Pointers to members are `never`, and the capsule-as-value half of them is [M32](../SATELLITE/M32-capsules-as-values.md).
