# CXX23/M147 — `return;` from a `void` function

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
void f() { return; }
```

## satellite

```
satellite.capsule f()
{
    satellite.return()
}
```

## What differs

`satellite.return()` is the no-value shape. `satellite.return(satellite)` is the one `main` uses, and `satellite.return(value)` answers something.
