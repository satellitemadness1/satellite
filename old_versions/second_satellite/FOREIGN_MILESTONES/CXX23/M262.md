# CXX23/M262 — `std::accumulate`, `std::reduce`, `std::ranges::fold_left`

**Introduced:** C++98 / C++17 / C++23. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
int total = std::accumulate(v.begin(), v.end(), 0);
```

## satellite

```
satellite.variable.number total = v.sum()
```

## What differs

`sum()` covers the common case exactly, because numbers are exact. A fold with any other function needs [M32](../SATELLITE/M32-capsules-as-values.md), and as a pipeline [M36](../SATELLITE/M36-ranges.md).
