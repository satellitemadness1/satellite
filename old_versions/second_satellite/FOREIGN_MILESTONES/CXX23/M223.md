# CXX23/M223 — `std::swap`, `std::exchange`

**Introduced:** C++98 / C++14. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
std::swap(a, b);
```

## satellite

```
satellite.variable.number spare = a
a = b
b = spare
```

## What differs

Three lines with a spare. Spacesuit handles swap the same way and swap only the handles.
