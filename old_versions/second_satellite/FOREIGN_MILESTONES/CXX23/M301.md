# CXX23/M301 — `std::this_thread::sleep_for`

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
std::this_thread::sleep_for(std::chrono::milliseconds(250));
```

## satellite

```
satellite.time.sleep(250)
```

## What differs

Milliseconds, per `satellite.help` (checked 2026-09-12).
