# CXX23/M151 — block comments `/* … */`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: open — no milestone and no refusal yet; this needs a decision.**

## C++

```cpp
/* several
   lines */
```

## satellite

```
// several
// lines
```

## What differs

**Checked 2026-09-12: refused**, `S0231` at the `/`. Only `//` comments exist.

**Open.** `foreign.cpp`'s guard would need a matching rule, because it skips
lines starting with `//` and a `/*` line would get advice.
