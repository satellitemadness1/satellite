# CXX23/M309 — `std::call_once`

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M40](../SATELLITE/M40-locks-and-atomics.md).**

## C++

```cpp
std::call_once(flag, init);
```

## Why

[M40](../SATELLITE/M40-locks-and-atomics.md). `satellite.library` values assigned from literals are resolved at parse time, which removes the most common use: lazily initialising a constant.
