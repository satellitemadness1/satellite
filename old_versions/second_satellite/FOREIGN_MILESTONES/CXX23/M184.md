# CXX23/M184 — object layout, standard-layout types, EBO

**Introduced:** C++98 / C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
std::is_standard_layout_v<T>
```

## Why

Layout is the interpreter's. No satellite program can observe it, so no guarantee about it is needed.
