# CXX23/M96 — `using enum`, `std::to_underlying`

**Introduced:** C++20 / C++23. Present in C++23 (ISO/IEC 14882:2024).
**Answer: open — no milestone and no refusal yet; this needs a decision.**

## C++

```cpp
using enum Mode;
int n = std::to_underlying(Mode::Read);
```

## Why

Both depend on `enum` (above). `using enum` also runs against DESIGN §1's rule that paths are written in full.
