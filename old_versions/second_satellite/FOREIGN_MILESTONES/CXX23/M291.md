# CXX23/M291 — random distributions `normal_distribution`, `poisson_distribution`

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: open — no milestone and no refusal yet; this needs a decision.**

## C++

```cpp
std::normal_distribution<double> d(0.0, 1.0);
```

## Why

**Satellite draws uniformly in a range.** No bell curve, no Poisson.

**Open, with a naming trap.** `satellite.random.normal` is already a tier, so
a normal *distribution* cannot use that word ("a word means one thing
everywhere", DESIGN §1).
