# CXX23/M74 — `[[noreturn]]`

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
[[noreturn]] void fail();
```

## Why

The only thing in satellite that does not return is a refusal, and the
interpreter already knows where those happen. There is nothing for a program to
declare.
