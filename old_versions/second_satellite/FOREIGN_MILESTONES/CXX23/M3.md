# CXX23/M3 — `std::cout`, `std::format`, `std::print`

**Standard:** C++23 §31.4 (`<iostream>`), §22.14 (`<format>`, C++20),
§31.7 (`<print>`, **new in C++23**).
**Answer: satellite says it** — with one real loss, noted below.

## C++

```cpp
std::cout << "x is " << x << "\n";          // C++98
std::print("x is {}\n", x);                 // C++23
```

## satellite

```
satellite.console.display("x is " + x)
```

## What differs

**`display` takes one value and adds the newline.** There is no `<<` chain and
no stream object; the line is built with `+` before it is handed over.

**A number concatenates onto a string without a conversion** — `"x is " + x`
works — which is the one thing that makes this bearable, because
`x.round().to_string()` is two hops and refuses (S0720, see
[../SATELLITE/M29](../SATELLITE/M29-method-chaining.md)).

**There is no format string, and none is planned.** `std::format`'s `{}` with
alignment, precision and locale is a small language of its own; satellite builds
lines by concatenation. For fixed decimals today: multiply, `.round()`, divide.

**`std::print` (C++23) is closer to satellite than `std::cout` ever was** — one
call, one line, no manipulators — which is worth saying to a reader arriving
from the newest standard: the shape they just learned is the shape here.
