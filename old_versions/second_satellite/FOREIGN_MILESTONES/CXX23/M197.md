# CXX23/M197 — explicit instantiation and `extern template`

**Introduced:** C++98 / C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
extern template class std::vector<int>;
```

## Why

These control where template code is compiled and linked. There is no object code or linker, and [M31](../SATELLITE/M31-user-generics.md)'s monomorphisation question is internal.
