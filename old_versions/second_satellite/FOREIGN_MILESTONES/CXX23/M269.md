# CXX23/M269 — `std::all_of`, `std::any_of`, `std::none_of`

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M32](../SATELLITE/M32-capsules-as-values.md).**

## C++

```cpp
bool ok = std::all_of(v.begin(), v.end(), positive);
```

## Why

Predicates, so [M32](../SATELLITE/M32-capsules-as-values.md). `contains(x)` is `any_of` for one exact value.
