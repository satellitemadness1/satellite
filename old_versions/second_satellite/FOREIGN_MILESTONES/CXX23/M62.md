# CXX23/M62 — `static_assert`

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M34](../SATELLITE/M34-compile-time-evaluation.md).**

## C++

```cpp
static_assert(sizeof(int) == 4);
```

## Why

A check that runs before the program does. Satellite has no compile-time
evaluation to run it in, and that is [M34](../SATELLITE/M34-compile-time-evaluation.md). `--check` already runs every pass and
reports without running, which is where such a check would print.
