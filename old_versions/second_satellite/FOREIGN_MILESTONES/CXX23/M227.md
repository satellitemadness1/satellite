# CXX23/M227 — `std::expected` monadic operations

**Introduced:** C++23. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M33](../SATELLITE/M33-catching-a-refusal.md).**

## C++

```cpp
parse(s).and_then(validate).or_else(report);
```

## Why

[M33](../SATELLITE/M33-catching-a-refusal.md) first (the value that holds an answer or a refusal), and [M32](../SATELLITE/M32-capsules-as-values.md) for the functions passed to it.
