# CXX23/M243 — `std::locale` and `<codecvt>`

**Introduced:** C++98 / C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M45](../CXX26/M45.md).**

## C++

```cpp
std::locale::global(std::locale("en_US.UTF-8"));
```

## Why

Locale and encoding are [M45](../CXX26/M45.md). `<codecvt>` was deprecated in C++17, which is a warning about doing this at the library level.
