# CXX23/M132 — unary minus

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
int x = -7;
```

## satellite

```
satellite.variable.number x = -7
```

## What differs

Checked 2026-09-12: `-7` works. (`example/scalars.satl` writes `0 - 7`, which predates this and is not needed.)
