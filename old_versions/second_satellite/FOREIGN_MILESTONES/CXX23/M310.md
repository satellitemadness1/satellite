# CXX23/M310 — `std::promise`, `std::packaged_task`

**Introduced:** C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M40](../SATELLITE/M40-locks-and-atomics.md).**

## C++

```cpp
std::packaged_task<int()> task(work); auto f = task.get_future();
```

## Why

Getting a value back from a thread. The CXX23 index sends futures to [M40](../SATELLITE/M40-locks-and-atomics.md), and [M43](../CXX26/M43.md) is where composing them lives.
