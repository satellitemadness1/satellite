# CXX23/M203 — lambda captures and init-capture

**Introduced:** C++11 / C++14. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M32](../SATELLITE/M32-capsules-as-values.md).**

## C++

```cpp
auto add = [base](int x) { return base + x; };
auto g = [n = compute()] { };
```

## Why

[M32](../SATELLITE/M32-capsules-as-values.md), and its page names the hard part: a capture that outlives the frame it was written in, which is exactly what DESIGN §7.2's frame-per-call must not lose.
