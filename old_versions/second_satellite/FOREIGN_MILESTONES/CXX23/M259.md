# CXX23/M259 — `front`, `back`, `size`, `empty`, `clear`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
v.front(); v.back(); v.empty();
```

## satellite

```
v.first()
v.last()
v.empty()
```

## What differs

`first` and `last` instead of `front` and `back`. The rest keep their names.
