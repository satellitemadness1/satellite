# CXX23/M191 — SFINAE and `std::enable_if`

**Introduced:** C++98 / C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
template <typename T, typename = std::enable_if_t<std::is_integral_v<T>>>
```

## Why

SFINAE is an accident of overload resolution that became a technique. Constraining a generic is [M36](M36.md) (concepts), which follows [M31](../SATELLITE/M31-user-generics.md). Satellite should never have the accident.
