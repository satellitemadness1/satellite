# CXX23/M119 — `std::pair`, `std::tuple`, `std::tie`, `std::apply`

**Introduced:** C++98 / C++11 / C++17. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite milestone [M35](../SATELLITE/M35-structured-bindings.md).**

## C++

```cpp
auto [q, r] = std::pair{7 / 2, 7 % 2};
```

## Why

A capsule answers exactly one value, so a pair is a spacesuit with two `call_`
verbs today. [M35](../SATELLITE/M35-structured-bindings.md) describes both halves: destructuring, and a capsule answering
more than one value, which needs a tuple type.
