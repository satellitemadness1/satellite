# CXX23/M246 — `std::set`, `std::unordered_set`

**Introduced:** C++98 / C++11. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
std::unordered_set<std::string> seen;
if (!seen.contains(k)) seen.insert(k);
```

## What differs

A map with a throwaway value is a set, and `has(k)` is the membership test. `list.contains(x)` also works, but it searches the list. Partial because the value is noise.
