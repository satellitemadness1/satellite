# CXX23/M318 — `<ctime>`: `time()`, `strftime`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
std::time_t t = std::time(nullptr);
```

## satellite

```
satellite.console.display(satellite.time.now())
```

## What differs

An instant can be read and displayed. Formatting it and doing arithmetic on it are PLAN.md's [M29](../SATELLITE/M29-method-chaining.md), as above.
