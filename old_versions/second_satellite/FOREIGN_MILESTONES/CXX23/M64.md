# CXX23/M64 — `#error` and `#warning`

**Introduced:** C++98 / C++23. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
#error "this platform is not supported"
```

## Why

There is no preprocessor to stop. To stop and say why when a condition is not
met, the milestone is [M42](../CXX26/M42.md) (contracts), which states the condition in the
program and has the refusal quote it.
