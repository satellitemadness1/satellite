# CXX23/M88 — hex `0xFF` and binary `0b1010` literals

**Introduced:** C++98 / C++14. Present in C++23 (ISO/IEC 14882:2024).
**Answer: satellite says it.**

## C++

```cpp
unsigned mask = 0xFF;
unsigned bits = 0b1010;
```

## satellite

```
satellite.variable.hex mask = xFF
satellite.variable.binary bits = b1010
```

## What differs

**The prefix is a letter without the zero.** Checked 2026-09-12: `xFF` and
`b0101` lex as literals, and `0xFF` is refused. The literal also has its own
type rather than being an integer. `mask.to_number()` answers `255`.
