# CXX23/M190 — class template argument deduction (CTAD)

**Introduced:** C++17. Present in C++23 (ISO/IEC 14882:2024).
**Answer: never.**

## C++

```cpp
std::vector v{1, 2, 3};   // vector<int>
```

## Why

Every declaration names its type, the same decision as [M7](M7.md). When [M31](../SATELLITE/M31-user-generics.md) lands, arguments are written out.
