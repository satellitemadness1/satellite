# CXX23/M250 — `std::priority_queue`

**Introduced:** C++98. Present in C++23 (ISO/IEC 14882:2024).
**Answer: partial — satellite has part of it.**

## C++

```cpp
std::priority_queue<int> pq;
```

## satellite

```
pq.append(x)
pq.sort_down()
pq.first()
```

## What differs

No heap: sort, then read the front. Correct, and slower per insert. A user key requires `sort_up(key)`, and a comparator function requires [M32](../SATELLITE/M32-capsules-as-values.md).
