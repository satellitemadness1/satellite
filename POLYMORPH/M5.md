# POLYMORPH M5 — a string's text used as a name

Written 2026-09-14. **Status: an idea, syntax sketched by the author.**

## The author's idea

"I have always wanted to write a program that uses strings as names of things,
and then to call those names with the name that was held inside of that
string."

```satellite
satellite.variable.string my_str = "some_text"

satellite.variable.string *my_str = "another_str"
```

The `*` marks `my_str`, so the interpreter uses the TEXT it holds as the name:
the second line declares a string called `some_text` holding `"another_str"`.

## What exists elsewhere

- **PHP's "variable variables"** are this idea: `$$name`.
- **Perl and bash** have their own forms of it.
- **Python** does it with `setattr(obj, my_str, value)`. It ran on 2026-09-14:
  `some_text = another_str`.

## What it costs in satellite

**Every name in satellite becomes a slot number before the program runs**
(DESIGN §7.1). That is where much of its speed comes from, and it is also why
a misspelt name is caught before anything runs. A name inside a string is
known only when its line runs, so:

- **Only marked names pay.** A `*` name is looked up by its text at run time,
  in a table beside the slots, and every unmarked name keeps its slot number
  and its speed.
- **A misspelling is found only when the line runs.** The error must name the
  string's text and the line that built it.

## Decisions for the author

- **D1. Is `*` the mark?** It reads like C's pointer `*`, and satellite
  already has `.pointer()` planned (M26) for a different meaning.
  Alternatives: `satellite.name(my_str)`, or `my_str.as_name()`.
- **D2. Where does the made-up name live?** In the capsule it was declared
  in, on an object (M2), or in a namespace (M4)?
- **D3. What if the text is already a name?** Refuse, replace, or shadow it
  the way a second declaration does (§7.4)?
- **D4. Which text is refused?** Text with spaces or dots, a reserved word
  like `satellite`, or empty text.
- **D5. Reading one back.** Does `*my_str` also READ the variable the text
  names, in an expression, or only declare it?
