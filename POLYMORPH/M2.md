# POLYMORPH M2 — `polymorph`: adding to one object while the program runs

Written 2026-09-14. **Status: proposed. Nothing built. The syntax is the
author's decision and is not made.**

## The idea, in the author's words

Each object can hold capsules of its own, added while the program runs, so
"the code can be polymorphic, and it can change inside of the main thread or
wherever the user wants to change it."

## The author's spellings

**Way 1**, a method on the object:

```satellite
some_spacesuit_name local_object

local_object.polymorph()
{
    satellite.protected
    {
        satellite.variable.string my_str = "void"
        satellite.capsule some_name()
        {
            // code here
        }
    }
}
```

**Way 2**, a bare statement with named areas:

```satellite
satellite.polymorph(object_name)
{
    satellite.polymorph.area("area_name")
    {
        // this code is added to "area_name"
    }
}
```

**Way 3**, combining the best of both. Not yet written down by the author.

## Recommended: Way 2's outside, Way 1's inside

```satellite
satellite.polymorph(local_object)
{
    satellite.protected
    {
        satellite.variable.string my_str = "void"
        satellite.capsule some_name()
        {
        }
    }
    satellite.public
    {
    }
}
```

- **`satellite.polymorph(...)` fits how satellite recognizes a statement.**
  DESIGN §6.1 dispatches on the word after `satellite.`; `satellite.statement.if`,
  `satellite.spacesuit` and `satellite.constructor(args) { }` all start that
  way. `local_object.polymorph() { }` starts with a user's name, which no row
  of that table handles. It would also collide with a spacesuit that declares
  its own capsule called `polymorph`, which is legal today.
- **Areas are words, not strings.** A misspelt `satellite.protectd` is caught
  before the program runs, with a caret; `area("protectd")` would only fail,
  or quietly create a new area, when its line is reached. And the inside is
  written exactly as inside a spacesuit.
- **A third kind of area needs a meaning first.** `protected` and `public`
  decide who can reach a member. An area named `"area_name"` would need its
  own answer to that before it can be built.

## What building it means

1. **Sharing, then copying.** Today every object of a spacesuit shares one
   copy of its capsules: 1,000,000 objects cost 937 bytes each with a 1-line
   capsule and 936 with a 3,000-line capsule (ACCESS_PLAN §5). An object
   KEEPS sharing until `polymorph` reaches it; then that one object gets its
   own table of additions, and the others are untouched. So a huge capsule is
   stored once however many objects exist, and only a polymorphed object pays
   for what was added to it.
2. **Speed.** satellite turns names into slot numbers before a program runs.
   The code inside `polymorph` is resolved when its line runs, only for that
   block. Every other line keeps its current speed, and a capsule call on an
   object that was never polymorphed costs exactly what it does today.
3. **Walls.** A capsule added in `satellite.protected` can be called from the
   object's own capsules and not from outside, the rule a spacesuit already
   enforces (S0516).
4. **Threads.** One thread adds to an object while another calls its capsules.
   The object's access list (THREAD.md T2) is held for the whole block, so a
   call sees the object entirely before or entirely after.
5. **`satellite.access`** shows the added capsules in the object's methods
   section, and ACCESS_PLAN A5's size column counts them in that object's size.

## Decisions for the author

- **D1. Way 1, Way 2 or Way 3.** Recommended above.
- **D2. Can an addition REPLACE a capsule the spacesuit already has?**
  Recommended: yes, for that object only.
  That is the polymorphism, and `access` should mark the row as replaced.
- **D3. Can a field be added after objects of the spacesuit exist?**
  Recommended: yes, on the polymorphed object only.
- **D4. The number.** `satellite.polymorph` would take the next free number
  under `satellite`: **`1 27`**, if `satellite.access` takes `1 26` first.
  Proposed, not assigned.

## Done when

An object gets a protected field and capsule plus a public capsule; the public
one calls the protected one; another object of the same spacesuit has
neither; outside code calling the protected one is refused; a replaced capsule
runs its new body on that object only; two threads (one adding, one calling)
show no torn state over 1,000 runs; and `access` shows it all.
