# POLYMORPH M3 — a spacesuit built inside `polymorph`

Written 2026-09-14. **Status: proposed. Needs M1 and M2.**

M1 lets a capsule declare a spacesuit, and M2 lets `polymorph` add a capsule
to one object. This milestone is both at once: **the capsule that `polymorph`
adds declares a brand-new spacesuit, and objects are made from that spacesuit
later, from anywhere that can reach it.**

## The author's program, 7 left-brackets

Spelled with M2's recommended outside; if the author picks Way 1 in M2, the
second line becomes `local_object.polymorph()`.

```satellite
satellite.capsule satellite.main()
{                                                          // 1
    test local_object
    satellite.polymorph(local_object)
    {                                                      // 2
        satellite.protected
        {                                                  // 3
            satellite.capsule my_test()
            {                                              // 4
                satellite.spacesuit something()
                {                                          // 5
                    satellite.protected
                    {                                      // 6
                        satellite.capsule new_function_from_new_capsule()
                        {                                  // 7
                             satellite.console.display("some success")
                        }
                    }
                }
            }
        }
    }
    satellite.return(satellite)
}
```

The author also wrote it with 6 brackets, leaving out the inner
`satellite.protected`; both are legal.

## What C++ does, measured 2026-09-14

C++ reaches at most 4 brackets for the same shape: `protected:` and `public:`
are labels with no bracket, and C++ has no word at all for the `polymorph`
level. It can run a program shaped like this only by calling the compiler
while it runs and loading the result (`poly7.cpp`), because every C++ class
is otherwise built before the program starts.

## What building it means

Nothing new beyond M1 and M2. Here M1's D1 (where the spacesuit lives) meets
M2's object: with M1's recommended answer, `something` lives on
`local_object`, and another capsule makes one with `local_object.something
made`.

## Decisions for the author

- **D1. How another capsule names `something`.** It follows from M1's D1;
  with (b) it is `local_object.something made`.
- **D2. What happens when `my_test()` runs twice** on the same object. M1's
  D2 applies.

## Done when

The program above runs; `my_test()` makes `something` exist; a DIFFERENT
capsule, called afterwards, makes two `something` objects and calls
`new_function_from_new_capsule()` through a public capsule; the same attempt
before `my_test()` runs is refused by name; and `access(local_object)` shows
`something` and its capsules.
