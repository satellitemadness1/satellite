
--------------------------------------------------------------------------------
SATELLITE 004: satellite.container
--------------------------------------------------------------------------------

satellite.container is the family of special types that hold other objects,
with a different kind for each job. satellite.container on its own is not a
type, and a line that declares one is refused (S110), so you always name the
kind:

  satellite.container.list       objects in a row, counted from 1 (std::vector)
  satellite.container.index      keys and their values, in the order they went
                                 in (a python dict)
  satellite.container.multiple   a name that may hold any one of several types
                                 (std::variant); a declaration, not a container
  satellite.container.map        keys and values (std::map): numbered, not built
                                 yet, so write satellite.container.index today

list, index and multiple are built in satellite 004. satellite.container.map,
satellite.container.arguments and satellite.container.result are numbered and
not built yet, and a line that declares one is refused (S110).

Braces make a list wherever a value goes: {1, 2}, and {} for an empty one. Any
container can hold any other, a list of lists or an index of lists, and a[1][2]
reaches in through both, to read or to write. What you write between < and >
says what a container holds, and it is checked on every way in; with no <> a
container holds anything. A container is a value, not a reference: b = a
copies it, and the copy costs nothing until one of them is written to. == and
!= compare what two containers hold, and < and > are refused, because there is
no order between two containers.

A satellite.main header may declare
satellite.container.list<satellite.variable.string> arguments, but satellite
004 does not fill that list yet: using arguments inside satellite.main is
refused (S201). satellite.main() with nothing between its brackets runs the
same.

example:

satellite.include(satellite)

satellite.capsule satellite.main()
{
    satellite.container.list<satellite.container.list<satellite.variable.number>> grid = {{1, 2}, {3, 4}}
    grid[2][1] = 99
    satellite.console.display(grid) // {{1, 2}, {99, 4}}

    satellite.container.index<satellite.variable.string, satellite.container.list> teams
    teams["red"] = {"ann", "bo"}
    teams["red"].append("cy")
    satellite.console.display(teams) // {"red": {"ann", "bo", "cy"}}
    satellite.console.display(teams["red"][2]) // bo

    satellite.container.list a = {1, 2}
    satellite.container.list b = a
    b.append(3)
    satellite.console.display(a) // {1, 2}
    satellite.console.display(b == {1, 2, 3}) // true

    satellite.container.multiple<satellite.variable.string, satellite.container.list> either = "text"
    either = {1}
    satellite.console.display(either) // {1}
    satellite.return(satellite)
}
