
--------------------------------------------------------------------------------
SATELLITE 004: satellite.variable.number
--------------------------------------------------------------------------------

satellite.variable.number is a whole number made of integers laid out next to
each other: unsigned long long ints side by side, with the sign carried as a
bool beside them. So it has no size limit but your memory, and it never wraps
around. A number that fits in one unsigned long long stays on a fast path, and
it spreads into more of them only when it has to.

You write it as digits, with a touching - in front for below zero: 34587, -7.
The operators are + - * / % and ^ for power (** is its second spelling), and
every one of them is written with a space on both sides. * / % bind tighter
than + and -, and ^ groups right to left, so 2 ^ 3 ^ 2 is 2 ^ 9. == != < >
<= and >= answer true or false.

/ on two numbers is a fraction, kept as written: 4 / 3 is 4/3 and 4 / 2 is 4/2
(satellite.help(fraction)). satellite.convert.number(7 / 2) is the whole number
nearest it, 4: .5 and above is one more, below .5 is not, so
satellite.convert.number(4 / 3) is 1, and satl warns on the screen when
something after the point was dropped. satellite.convert.float(4 / 3) is the
float (satellite.help(convert)). A number name given a / b is refused before
anything runs, told to declare a fraction or to write
satellite.convert.number(a / b). % takes the sign of the number being
divided: -7 % 2 is -1. 1 / 0 is refused (S401). 2 ^ -1 is 0.5: an answer a
whole number cannot hold becomes a satellite.variable.float, and 4.0 / 3 is the
float (satellite.help(float)).

A number meets text by what the text says: 5 + "2" is the number 7, because
"2" spells a number, and 5 + "a" is the text 5a. Every other conversion you say
out loud with a method, and a number's methods are its own words, written
under satellite: n.satellite.string (also .satellite.to_string and
.satellite.str) is its base 10 text, n.satellite.binary (also .satellite.bin)
its base 2 text, n.satellite.hex its base 16 text, n.satellite.reverse() turns
its digits round and keeps the sign, and n.satellite.add(x) is +.

Its other words, each answering a new number and leaving n as it was:
n.satellite.abs() is n without its sign; n.satellite.max(x) and
n.satellite.min(x) the larger and the smaller of n and x;
n.satellite.clamp(low, high) holds n between low and high; n.satellite.power(x)
is n ^ x and n.satellite.modulus(x) is n % x, the operators' own answers;
n.satellite.shift_left(k) and n.satellite.shift_right(k) multiply and divide n
by 2 ^ k; n.satellite.digits() counts its decimal digits and n.satellite.bytes()
the bytes it takes. A number is whole, so n.satellite.floor(),
n.satellite.ceil(), n.satellite.round() and n.satellite.truncate() answer n.
n.satellite.sqrt() is numbered and not built yet (S210).

What it refuses today: a touching sign, 4+3 (S110), and n += 1 (S210, "write
n = n + ..."). A number with a point in it, 12.34, is a float, not a number, and
a number name given one is refused ("it holds a float"). A number's word with a
bare period, n.max(3), is refused before anything runs, naming n.satellite.max
(S110), and so is one it does not have: n.find("8") is a string's (S301).

example:

satellite.include(satellite)

satellite.capsule satellite.main(satellite.variable.arguments arguments)
{
    satellite.variable.number n = 87
    satellite.console.display(n + 13)                       // 100
    satellite.console.display(4 / 3)                        // 4/3
    satellite.console.display(satellite.convert.number(4 / 3))  // 1
    satellite.console.display(-7 % 2)                       // -1
    satellite.console.display(2 ^ 3 ^ 2)                    // 512
    satellite.console.display(2 ^ 70)                       // 1180591620717411303424
    satellite.console.display(n > 50)                       // true
    satellite.console.display(n.satellite.binary)           // 1010111
    satellite.console.display(n.satellite.hex)              // 57
    satellite.console.display(n.satellite.reverse())        // 78
    satellite.console.display(n.satellite.max(100))         // 100
    satellite.console.display(n.satellite.clamp(0, 50))     // 50
    satellite.console.display(n.satellite.power(2))         // 7569
    satellite.console.display(n.satellite.modulus(10))      // 7
    satellite.console.display(n.satellite.shift_left(1))    // 174
    satellite.console.display(n.satellite.digits())         // 2
    satellite.return(satellite)
}

refused today:

satellite.console.display(4+3)

prints:

S110: LINE_NOT_UNDERSTOOD
satl(run): every math operation is written with a space on both sides of the
sign, and this + has none
