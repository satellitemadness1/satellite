
--------------------------------------------------------------------------------
SATELLITE 004: satellite.variable.fraction
--------------------------------------------------------------------------------

satellite.variable.fraction is two numbers tied together, one above the line and
one below it. You write it with a slash that touches both numbers: 1/3. That is
the whole difference between a fraction and division -- 1 / 3, with a space on
both sides, is whole-number division and answers 0, and a fraction name given a
spaced slash is refused before anything runs: "a fraction is written with a
touching slash: 1/3".

Each part is held as a satellite.variable.float, and shown as the whole number
it is: 1/3 shows 1/3, never 1.0/3.0, and a part with digits after the point
shows them, 1.5/2. A fraction stays as it was written -- 2/4 shows 2/4 -- but
two fractions compare by what they are worth, so 2/4 == 1/2 is true and 1/3 <
1/2 is true. The sign goes on top: -1/3. A bottom number of 0 is refused, and a
whole number given to a fraction name becomes that number over 1: 3 shows 3/1.

.numerator and .denominator are its two parts, and .string is how it is shown.

Not built yet: arithmetic with fractions (1/3 + 1/3 is refused, "fraction
arithmetic is not built yet"), a fraction of names (a/b), a fraction meeting a
float, a percentage or any other new type, and .number.

example:

satellite.include(satellite)

satellite.capsule satellite.main(satellite.variable.arguments arguments)
{
    satellite.variable.fraction third = 1/3
    satellite.variable.fraction half = 2/4
    satellite.console.display(third) // 1/3
    satellite.console.display(half) // 2/4
    satellite.console.display(half == 1/2) // true
    satellite.console.display(third < half) // true
    satellite.console.display(third.denominator) // 3
    satellite.console.display(1.5/2) // 1.5/2
    satellite.console.display(1 / 3) // 0
    satellite.return(satellite)
}
