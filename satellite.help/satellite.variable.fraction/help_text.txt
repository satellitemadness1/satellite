
--------------------------------------------------------------------------------
SATELLITE 004: satellite.variable.fraction
--------------------------------------------------------------------------------

satellite.variable.fraction is two numbers tied together, one above the line and
one below it. You write it with a slash that touches both numbers, 1/3, and two
numbers divided are one too, kept as written: 1 / 3 is 1/3, 4 / 2 is 4/2 and
total / count is a fraction whenever both are numbers. It is never put in
lowest terms. A binary or a hex divided stays a whole number. For the whole
number nearest a fraction write satellite.convert.number(x) -- 7/2 is 4, .5 and
above is one more -- and satellite.convert.float(x) for its float
(satellite.help(convert)).

Each part is held as a satellite.variable.float, and shown as the whole number
it is: 1/3 shows 1/3, never 1.0/3.0, and a part with digits after the point
shows them, 1.5/2. A fraction stays as it was written -- 2/4 shows 2/4 -- but
two fractions compare by what they are worth, so 2/4 == 1/2 is true and 1/3 <
1/2 is true. The sign goes on top: -1/3, and 1 / -3 is -1/3. A bottom number of
0 is refused, and a whole number given to a fraction name becomes that number
over 1: 3 shows 3/1.

.satellite.numerator and .satellite.denominator are its two parts, each a whole
number when it is one and a float when it is not, and .satellite.string is how
it is shown. Since 2026-10-11 a fraction's words are written with satellite. in
front of them, as every word built into the language is, on a literal too:
1/3.satellite.numerator is 1. The old third.numerator is refused before
anything runs, naming the new spelling.

Not built yet: arithmetic with fractions (1/3 + 1/3 is refused, "fraction
arithmetic is not built yet", and so is a / b + 1 -- before anything runs when
a and b are named numbers), a touching slash between names (a/b -- write
a / b), a fraction meeting a float, a percentage or any other new type, and
.satellite.number.

example:

satellite.include(satellite)

satellite.capsule satellite.main(satellite.variable.arguments arguments)
{
    satellite.variable.fraction third = 1/3
    satellite.variable.fraction half = 2/4
    satellite.console.display(third) // 1/3
    satellite.console.display(half) // 2/4
    satellite.console.display(half == 1/2) // true
    satellite.console.display(third < half) // true
    satellite.console.display(third.satellite.denominator) // 3
    satellite.console.display(1.5/2) // 1.5/2
    satellite.console.display(1 / 3) // 1/3
    satellite.console.display(satellite.convert.number(7 / 2)) // 4
    satellite.return(satellite)
}
