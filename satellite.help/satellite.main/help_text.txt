
--------------------------------------------------------------------------------
SATELLITE 004: satellite.main()
--------------------------------------------------------------------------------

satellite.main is the entry point for the app, satellite's int main(). It is a
capsule, declared satellite.capsule satellite.main(), and your program begins
inside it and ends inside it. There are no globals in satellite: a line written
outside every capsule has nowhere to put its result and no moment to run in, so
everything your program does starts from a line in main, or from a capsule that
main calls.

The file you run needs three things, and satl looks for all three before
anything runs:

satellite.include(satellite)          this file is a program   (S101, exit 10)
satellite.capsule satellite.main()    where it begins          (S102, exit 11)
satellite.return(satellite)           where it ends            (S103, exit 12)

A file without satellite.include(satellite) is a spaceship, a file for another
file to include, and satl will not start it. satellite.main is written once, at
the top of its file: a second one is refused as declared twice (S202), and one
inside a satellite.namespace is refused (S110). Leave off satellite.capsule and
it is not a capsule at all -- satl stops with "no satellite.main to begin in".

Only the file you run has its main run. A file you include may have a main of
its own, so that it can be run by itself too; including it gives you its
capsules, and its main never runs.

main takes nothing, satellite.main(), or one parameter: the arguments variable,
which holds every row satl holds -- the words your program was started with,
satl's settings, and facts gathered when satl starts -- read by name, as
arguments.argument_1 or arguments.username. The author writes it
satellite.variable.arguments arguments since 2026-09-22; the older
satellite.container.list<satellite.variable.string> arguments is the same
variable, and you may give it any name. See satellite.help(arguments).

You run a program with satl hello.satl, or by typing interpret hello.satl or
run hello.satl at the satl prompt. When main reaches satellite.return(satellite)
the program ends, and satl exits 0.

example:

satellite.include(satellite)

satellite.capsule satellite.main(satellite.container.list<satellite.variable.string> arguments)
{
    satellite.console.display("Hello, World!") // Hello, World!
    satellite.console.display(42)              // 42
    satellite.return(satellite)
}
