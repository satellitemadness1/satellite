--------------------------------------------------------------------------------
SATELLITE 004: satellite.return()
--------------------------------------------------------------------------------

satellite.return(args) ends the capsule it is written in -- from wherever it
stands, inside an if, a while or a for -- and hands back what is between its
brackets. In main, satellite.return(satellite) ends the program, and satl exits
0. satellite.return() and satellite.return(satellite) hand back nothing. A
capsule other than main may leave it out: reaching its closing } ends it the
same way, with nothing handed back.

A program needs at least one. satl looks for a satellite.return anywhere in the
file you run, and refuses a file with none before anything runs (S103, exit
12) -- execution ends inside main, and the file has to say so. Its place is the
last line of main.

What a capsule answers is said after its brackets with satellite.returns(type),
and whatever its satellite.return hands back is measured against that type when
it runs. A capsule written without satellite.returns may still hand a value
back; the author's programs have hundreds that do. A capsule is called for its
answer inside any line:

satellite.variable.number n = five()

A capsule that declares satellite.returns and hands back nothing, and a call
whose answer is used from a capsule that can never hand one back, are refused
before anything runs (S240). One whose answer is used and that ended without
handing one back, the way it went, is refused when it happens -- also S240.

At the satl prompt there is nothing to return from, and satellite.return is
refused there by name.

example:

satellite.include(satellite)

satellite.capsule sign_of(satellite.variable.number n) satellite.returns(satellite.variable.string)
{
    satellite.statement.if (n < 0)
    {
        satellite.return("below zero")
    }
    satellite.statement.if (n == 0)
    {
        satellite.return("zero")
    }
    satellite.return("above zero")
}

satellite.capsule satellite.main()
{
    satellite.console.display(sign_of(-5))
    satellite.console.display(sign_of(0))
    satellite.console.display(sign_of(7))
    satellite.return(satellite)
}

prints:

below zero
zero
above zero
