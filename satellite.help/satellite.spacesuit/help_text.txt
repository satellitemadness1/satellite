--------------------------------------------------------------------------------
SATELLITE 004: satellite.spacesuit
--------------------------------------------------------------------------------

satellite.spacesuit is satellite's class: a type you write yourself, with its
own variables and its own capsules, that your program makes objects of.
satellite.class is its second spelling and is the same word -- the author,
2026-09-22: "class will be spacesuit alias class, so a class remains a
spacesuit and that is my final answer".

A spacesuit has sections, written side by side between its { and }:

- satellite.protected { } holds its fields -- a type and a name, and a value if
  you give one -- and the capsules only its own capsules may call.
- satellite.public { } holds the capsules whoever has an object may call.
- satellite.constructor(args) { } sits beside them and runs when an object is
  made, after every field has its first value. It is public, and hands nothing
  back.

An object is made by declaring it: the spacesuit's name, the object's name, and
the constructor's arguments right there -- greeter host("satl"). One whose
constructor takes nothing is just greeter host. A spacesuit of another file is
named through that file, narration.narrator voice("main", "full"). Declaring the
same name again makes a new object; the old one lives on in whatever still holds
it.

Inside its capsules a spacesuit's fields and capsules are their bare names --
there is no "this". From outside, an object's public capsules are called on it,
host.greet(), inside any line: satellite.variable.string said = host.greet().
Fields are reached from inside the spacesuit only, never as host.name, so a
public capsule that answers one is the way to read it.

An object is a reference: greeter other = host names the same object, and a
capsule handed one changes the caller's. Its type can be a capsule's parameter
or what a list holds, satellite.container.list<greeter>, and a capsule can hand
one back. A field of a spacesuit's type with nothing after its name starts
empty, until a capsule gives it an object.

Every object also answers pointer(), reference() and ok(), whatever its
spacesuit declares -- the author, 2026-10-02: ".pointer() be something that
points at the object, and .reference() something that is a copy of the object,
so the object can be emptied and the reference is still there".

- host.pointer() points at host's object and does not keep it living: once
  nothing else holds the object -- no name, no field, no item of a list -- it is
  gone, and the pointer is empty. greeter p = host.pointer() is a greeter, and
  p.greet() runs on host's object. A pointer is how an object points back at
  its parent, or at itself, without the two keeping each other alive for ever.
- host.reference() is an exact copy: its fields, and every object it holds,
  copied all the way down, and its own from then on. A pointer inside it points
  at the copy of what it pointed at, when that was copied too.
- ok() is true of an object, and of a pointer whose object is still there. A
  capsule called through a pointer whose object is gone stops with S260.

A spacesuit may hold spacesuits of its own, written in its satellite.public or
satellite.protected. The outer one's capsules and fields name it bare; from
outside a public one is outer.inner, and a protected one cannot be named. Its
capsules run on an object of it, and see its own fields -- not the outer one's.

A spacesuit may extend one other spacesuit, named in its brackets:
satellite.spacesuit eclipse(view). Its objects have view's fields first and then
its own, and view's capsules too: eclipse's capsules call view's by their bare
names, and a view name may hold an eclipse. A capsule it declares again replaces
view's for its objects. Every constructor runs, view's first; the arguments go
to the nearest one. A built type in the brackets --
satellite.spacesuit name(satellite.variable.string) -- is MILESTONES M35, and not
built yet.

satl refuses these before anything runs: a field or a protected capsule reached
from outside (S230), a name the spacesuit does not have, an object given the
wrong number of arguments, arguments with no constructor to take them, a field
whose value names another field, and a spacesuit declared inside a capsule
(S210).

example:

satellite.include(satellite)

satellite.spacesuit greeter()
{
    satellite.protected
    {
        satellite.variable.string name = ""
        satellite.variable.number times = 0
    }

    satellite.constructor(satellite.variable.string given)
    {
        name = given
    }

    satellite.public
    {
        satellite.capsule greet()
        {
            times = times + 1
            satellite.return("hello from " + name + ", " + times.to_string())
        }
    }
}

satellite.capsule satellite.main()
{
    greeter host("satl")
    satellite.console.display(host.greet())
    greeter same = host
    satellite.console.display(same.greet())
    satellite.return(satellite)
}

prints:

hello from satl, 1
hello from satl, 2

example, a pointer and a reference:

satellite.include(satellite)

satellite.spacesuit counter()
{
    satellite.protected
    {
        satellite.variable.number count = 0
    }

    satellite.public
    {
        satellite.capsule bump()
        {
            count = count + 1
            satellite.return(count)
        }
    }
}

satellite.capsule satellite.main()
{
    counter first
    counter looking = first.pointer()
    counter copied = first.reference()
    satellite.console.display(looking.bump())
    satellite.console.display(first.bump())
    satellite.console.display(copied.bump())
    counter spare
    first = spare
    satellite.console.display(looking.ok())
    satellite.console.display(copied.bump())
    satellite.return(satellite)
}

prints:

1
2
1
false
2
