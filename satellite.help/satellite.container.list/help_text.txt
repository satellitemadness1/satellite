
--------------------------------------------------------------------------------
SATELLITE 004: satellite.container.list
--------------------------------------------------------------------------------

satellite.container.list is satellite's std::vector: a row of objects, kept in
the order you put them in. You write one with braces wherever a value goes, so
{1, 2, 3} is a list, {} is a list of nothing, {1, "two"} is a list of mixed
items and {{1, 2}, {3}} is a list of lists. satellite.container.list() is {}
said in words, as 003 spelled it -- a list of nothing, in a capsule or as a
spacesuit's field -- and it takes nothing. satellite.container.list<type>
checks every item against that type on every way in (the declaration, a[n] = x,
.satellite.append and .satellite.insert) and refuses one that does not fit;
with no <> a list holds anything.

a[n] reads item n and a[n] = x replaces it, counting from 1, as a file's lines
do; in a list of lists a[x][y] reads item y of item x, and a[x][y] = v and
a[x].satellite.append(v) change it. a[0] is refused (S413: the first item is
a[1]), and so is an n past the end (S501); writing past the end does not make
the list longer: .satellite.append does that. b = a COPIES the list, so
changing b leaves a alone, and the copy costs nothing until one of them is
written to.

Since 2026-10-10 every word a list has is written with satellite. in front of
it -- names.satellite.append("bo"). The old names.append("bo") is refused, and
the refusal names the new spelling.

.satellite.append(x) .satellite.insert(n, x) .satellite.remove(x)
.satellite.remove_at(n) .satellite.remove_first() .satellite.remove_last()
.satellite.truncate(n) .satellite.reserve(n) and .satellite.clear change the
list itself, so they need a name to change: {1, 2}.satellite.append(3) is
refused. .satellite.reserve(n) makes room for n items at once and changes no
item. Everything else answers a new value and leaves the list alone:
.satellite.size .satellite.empty .satellite.first .satellite.last
.satellite.contains(x) (or .satellite.contain), .satellite.index_of(x) and
.satellite.search(x), which answer a position or 0, .satellite.reverse(),
.satellite.sum (every item added with +, and 0 for a list of nothing),
.satellite.max and .satellite.min (the largest and smallest by what each is
worth), and .satellite.join(separator), one string of every item's text with
separator between. .satellite.sort() orders nothing on its own; follow it with
.satellite.by_name(), which orders by how each item reads (a to z, then A to Z,
then digits), or .satellite.by_value(), which puts the smallest first, and put
.satellite.reverse() after either to go the other way. There is no for-each
loop yet, so walk a list with satellite.statement.for and a[i].

The old .satellite.sort("down"), .satellite.sort_down() and
.satellite.sort_up() are refused:
.satellite.sort().satellite.by_name().satellite.reverse() replaced them.
.satellite.sort("key") and .satellite.sort("value") are a map's, and a map
refuses
.satellite.by_name() and .satellite.by_value(). On an index, .satellite.sum
.satellite.max .satellite.min and .satellite.join ask you to say which half -- scores.satellite.values.satellite.sum,
scores.satellite.keys.satellite.join(", ").

example:

satellite.include(satellite)

satellite.capsule satellite.main()
{
    satellite.container.list<satellite.variable.string> names = {"zoe", "al"}
    names.satellite.append("bo")
    satellite.console.display(names) // {"zoe", "al", "bo"}
    satellite.console.display(names[1]) // zoe
    satellite.console.display(names.satellite.size) // 3
    satellite.console.display(names.satellite.contains("al")) // true
    satellite.console.display(names.satellite.sort().satellite.by_name()) // {"al", "bo", "zoe"}
    satellite.container.list down = names.satellite.sort().satellite.by_name().satellite.reverse()
    satellite.console.display(down) // {"zoe", "bo", "al"}
    satellite.console.display(names) // {"zoe", "al", "bo"}

    satellite.container.list row = {30, 4, 100}
    satellite.console.display(row.satellite.sort().satellite.by_value()) // {4, 30, 100}
    satellite.console.display(row.satellite.sort().satellite.by_name()) // {100, 30, 4}
    satellite.console.display(row.satellite.sum) // 134
    satellite.console.display(row.satellite.max) // 100
    satellite.console.display(names.satellite.join(", ")) // zoe, al, bo

    satellite.container.list<satellite.container.list<satellite.variable.number>> grid = satellite.container.list()
    grid.satellite.append({1, 2})
    grid.satellite.append(satellite.container.list())
    grid[2].satellite.append(3)
    satellite.console.display(grid[2][1]) // 3
    grid[1][2] = 20
    satellite.console.display(grid) // {{1, 20}, {3}}

    satellite.container.list copy = names
    copy[1] = "ZOE"
    satellite.console.display(names[1]) // zoe

    satellite.statement.for(satellite.variable.number i = 1; i <= row.satellite.size; i++)
    {
        satellite.console.display(row[i] + 1) // 31, then 5, then 101
    }
    satellite.return(satellite)
}
