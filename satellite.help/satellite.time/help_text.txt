
--------------------------------------------------------------------------------
SATELLITE 004: satellite.time
--------------------------------------------------------------------------------

Lengths of time, the clock, and the wait. A time is written with its unit
touching the number -- s for seconds, ms for milliseconds, ns for nanoseconds
-- or made by a word, and every way makes the same satellite.variable.time:

    1s          250ms          30ns          1.5s
    satellite.time.second(1)            satellite.time.s(1)
    satellite.time.millisecond(250)     satellite.time.ms(250)
    satellite.time.nanosecond(30)       satellite.time.ns(30)

s, ms and ns are the second spellings of second, millisecond and nanosecond.
Each word takes a whole number or a float: satellite.time.second(1.5) is 1.5s.

satellite.time.now(unit) reads the computer's clock: the time since 1970-01-01
00:00:00 UTC, read fresh at every call. It is a time like any other, and every
nanosecond is kept whatever the unit -- the unit is only how it is shown. It
takes one of six spellings, written exactly, and nothing between the brackets
is the nanosecond:

    satellite.time.now("seconds")          or "s"     1793036700.123456789s
    satellite.time.now("milliseconds")     or "ms"    1793036700123.456789ms
    satellite.time.now("nanoseconds")      or "ns"    1793036700123456789ns
    satellite.time.now()                              1793036700123456789ns

example:

    satellite.include(satellite)

    satellite.capsule satellite.main()
    {
        satellite.variable.time second = satellite.time.now("seconds")
        satellite.variable.time milli = satellite.time.now("ms")
        satellite.console.display(second)      // 1793036700.123456789s
        satellite.console.display(milli)       // 1793036700123.456789ms
        satellite.console.display(satellite.time.now())
        satellite.return(satellite)
    }

A literal unit that is not one of the six -- "minutes", 5, 1s, -1s -- is
refused before anything runs, with S301 TYPES_DO_NOT_MEET, and a unit worked
out, such as one held in a string name, is judged when its line runs. now is
called with brackets: satellite.time.now() or satellite.time.now("s"). A time
is shown in another unit by its own .satellite.time.convert(unit) -- see
satellite.help(satellite.variable.time).

satellite.time.sleep(t) waits on the thread that calls it for at least t, and
then goes on: satellite.time.sleep(1s), satellite.time.sleep(250ms), or a
time's name. The nanosecond is the smallest unit, and how much longer than
asked a sleep takes is the machine's to say -- a 1ns sleep takes as long as
asking the clock does. 0s returns at once. A line displayed before a sleep is
on the screen during it, and other threads go on running and displaying while
one sleeps.

example:

    satellite.include(satellite)

    satellite.capsule satellite.main()
    {
        satellite.console.display("waiting a quarter of a second")
        satellite.time.sleep(250ms)
        satellite.variable.time pause = satellite.time.millisecond(100)
        satellite.time.sleep(pause)
        satellite.console.display("done")
        satellite.return(satellite)
    }

A sleep can always be stopped: a thread asked to stop with .satellite.stop(),
and satellite.return(satellite) reached on any thread, end it within a tenth of
a second, and so does Ctrl-C at the prompt. Ctrl-C while a file runs ends satl
itself, as it always does. A sleep in a capsule of an object whose
.satellite.lock() is on lets go of the lock while it waits, as
.satellite.join() does, and takes it back after.

A bare number names no unit -- 5 seconds and 5 nanoseconds are a billion times
apart -- so the unit is always written: 5s, 5ms or 5ns. Before anything runs,
this is refused:

    satellite.include(satellite)

    satellite.capsule satellite.main()
    {
        satellite.time.sleep(5)
        satellite.return(satellite)
    }

A time below zero is a time (-1s), and a sleep refuses it: S440 TIME_BELOW_ZERO.
003's satellite.time.sleep(90, "ms") is refused before anything runs, and told
to write 90ms. satellite.time.new is not built yet.
See satellite.help(satellite.variable.time) for the time itself.
