--------------------------------------------------------------------------------
SATELLITE 004: satellite.container.map
--------------------------------------------------------------------------------

satellite.container.map is a container of keys and the values filed under them
(word 1 4 1). It is the same container as satellite.container.index (word
1 4 5): either word declares it, and a refusal says the word you wrote. It is a
python dict rather than a std::map. Its keys come back in the order you put
them in, not sorted, and finding a key costs one hash.

satellite.container.map<key, value> age declares an empty one, and with no <>
it takes any key and any value. satellite.container.map() is an empty one
too. A map written whole is braces around key: value pairs --
{"zoe": 30, "al": 4} -- which is how satl shows one; a key written twice keeps
its first place and its last value. age["al"] = 4 puts a key in, or changes the
value of a key already there without moving it. age["al"] reads it, and a key
that is not there is refused (S501) rather than answered with nothing. A key
must be a number, a string, a bool, a binary or a percentage, never a list or
another map, because a key must not be able to change after it is filed; 1
and "1" are two different keys. A value can be anything, a list or a map
included, to any depth: teams["red"][2] reaches into the list filed under
"red", and satellite.access(teams) shows the way into every level.

Since 2026-10-11 every word a map has runs its own number --
satellite.container.map.<word>, 1 4 1 n -- and is written with satellite. in
front of it, as a list's and a string's are: age.satellite.size. The old
age.size is refused, and the refusal names the new spelling. The same words are
an index's, the arguments variable's and an info's every item's: each of them is
a map.

.satellite.set(k, v) is age[k] = v, .satellite.get(k) is age[k], and
.satellite.has(k) is .satellite.contains(k) (or .satellite.contain).
.satellite.set(k, v), .satellite.remove(k), .satellite.remove_first(),
.satellite.remove_last() and .satellite.clear change the map itself, so they
need a name to change. .satellite.keys and .satellite.values answer two lists in
the same order, .satellite.first and .satellite.last are the first and last KEY,
.satellite.reverse() answers the keys back to front as a list, and
.satellite.size and .satellite.empty say how many there are.
.satellite.remove_first() and .satellite.remove_last() take out the oldest and
the newest entry. .satellite.append .satellite.insert .satellite.remove_at
.satellite.truncate .satellite.index_of and .satellite.search are refused,
because a map has keys and not positions. Two maps are == when they
hold the same entries, whatever order those went in.

.satellite.sort() puts a map in order by its keys, and is .satellite.sort("key")
in fewer words; .satellite.sort("value") puts it in order by its values. Each
answers the map with its entries in the new order and leaves the name as it was:
count = count.satellite.sort("value") keeps the order. The width comes first,
then a to z and 0 to 9: a whole number by how many digits it has and then by its
digits, so 9 comes before 10 and 100, and every negative number before 0; a
string by how many characters it has and then by its characters in satellite's
own order (a to z, then A to Z, then 0 to 9), so "bo" comes before "zoe" before
"alice", and "file2" before "file10"; a float, a fraction and the rest by what
each is worth. Entries that tie keep the order they went in. A number key beside
a string key, or two lists, have no order between them, and .satellite.sort
refuses them rather than guess. .satellite.sort().satellite.by_name() and
.satellite.sort().satellite.by_value() are a list's: a map refuses them, and
count.satellite.keys.satellite.sort().satellite.by_name() orders its keys alone.

example:

satellite.include(satellite)

satellite.capsule satellite.main()
{
    satellite.container.map<satellite.variable.string, satellite.variable.number> age
    age["zoe"] = 30
    age["al"] = 4
    age["bo"] = 100
    age["zoe"] = 31
    satellite.console.display(age) // {"zoe": 31, "al": 4, "bo": 100}
    satellite.console.display(age["al"]) // 4
    satellite.console.display(age.satellite.keys) // {"zoe", "al", "bo"}
    satellite.console.display(age.satellite.values) // {31, 4, 100}
    satellite.console.display(age.satellite.contains("bo")) // true
    age.satellite.set("cy", 7)
    satellite.console.display(age.satellite.get("cy")) // 7
    age.satellite.remove("al")
    satellite.console.display(age.satellite.size) // 3
    satellite.console.display(age.satellite.first) // zoe
    satellite.console.display(age.satellite.reverse()) // {"cy", "bo", "zoe"}
    satellite.container.list<satellite.container.map<satellite.variable.string, satellite.variable.number>> rows = {{"a": 1}, {"b": 2}}
    satellite.console.display(rows[2]["b"]) // 2
    satellite.container.map<satellite.variable.string, satellite.variable.number> count = {"to": 4, "be": 2, "or": 1, "not": 3}
    satellite.console.display(count.satellite.sort()) // {"be": 2, "or": 1, "to": 4, "not": 3}
    satellite.console.display(count.satellite.sort("value")) // {"or": 1, "be": 2, "not": 3, "to": 4}
    satellite.console.display(count.satellite.sort("value").satellite.last) // to
    satellite.return(satellite)
}

satellite.include(satellite)

    satellite.return(satellite)
